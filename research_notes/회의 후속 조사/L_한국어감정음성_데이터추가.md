# L. 한국어 감정 음성 데이터 추가 조사 (유료 포함)

> 조사일: 2026-11-07 · 목적: 한벗 SER(음성 감정 인식) 학습·평가용 한국어 감정 음성 데이터를 기존 목록(`데이터셋 조사/hanbeot_datasets.md`) 밖에서 추가로 찾음
> 검증 표시: 🟢 = 실제 페이지를 열어 확인함 · 🟡 = 검색 스니펫·2차 자료만 봄
> 적합도: 🟢 높음 · 🟡 조건부 · 🔴 낮음/참고만

## 한 줄 결론

- **"한국어 + 감정 라벨 + 상업 라이선스"를 다 갖춘 기성품(OTS)은 거의 없음.** 상용 쪽에서 확인된 건 Deeply(3단계 음성 감정, 290h, 견적)와 DataoceanAI 감정 TTS 코퍼스(소규모, 연기) 정도임. Nexdata·Appen·Magic Data·Defined.ai는 한국어 일반 음성만 있고 감정 라벨 붙은 한국어 상품은 못 찾음.
- **양으로 보면 AI Hub 미확인 데이터셋이 가장 큼.** 감정 태그가 달린 음성이 10개 더 있음. 특히 **119 신고 음성(실제 위기 통화, 3,064h, 불안/당황 태그)**, **공공분야 고객응대(3,300h, 문장 단위 8감정 태그)**가 한벗에 직접 쓸모 있음.
- **K-EmoCon은 영어 토론이라서 한국어 SER에는 못 씀**(논문 원문에서 확인).
- **결론: 상용 한국어 감정 음성은 거의 없음 → AI Hub가 주력임.** 부족분은 **자체 수집이나 업체 맞춤 수집(크라우드웍스·Nexdata·Deeply 등 견적)**으로 채움. 수집 기준은 청년 화자임.

## 구매·신청 전 확인할 질문

**데이터 자체**
- [ ] **화자 연령대(20~30대 비율)**: 20대·30대가 각각 몇 명이고 몇 시간인지? 화자 단위로 나눌 수 있는지?
- [ ] **자연 발화인지**: 대본 낭독인지, 연기 지시인지, 실제 대화인지? 감정을 유도했다면 방법은?
- [ ] **라벨 단위**: 발화(문장) 단위인지, 통화·세션 단위인지? 시작·끝 타임스탬프가 있는지?
- [ ] **라벨 근거**: 음성을 듣고 붙였는지, **텍스트만 보고** 붙였는지? (71592는 텍스트 기반 의심, 71615도 확인 필요)
- [ ] **평가자 수와 일치도**: 발화당 몇 명이 라벨링했는지? 카파·알파 같은 일치도 값이 있는지? 다수결인지 분포 라벨인지?
- [ ] **감정 분포**: 중립 비율은? (539는 무표정 79%) 불균형을 감안해 클래스별 시간을 받을 수 있는지?
- [ ] **녹음 환경**: 스마트폰·원거리·잡음 조건이 있는지, 샘플레이트는?
- [ ] **샘플**: 구매 전에 샘플 오디오와 라벨 JSON을 받아볼 수 있는지?

**라이선스(상용 업체)**
- [ ] **상업 라이선스 범위**: 학습한 모델을 유료 앱에 넣어도 되는지? 기간 제한(영구/연 단위)이 있는지?
- [ ] **재배포·파생물**: 증강한 데이터나 임베딩을 팀 밖과 공유해도 되는지? 데이터 일부를 논문이나 데모에 써도 되는지?
- [ ] **해외 처리**: 해외 클라우드(GPU, API)에 올려도 되는지?
- [ ] **화자 동의**: 화자가 "상업 AI 학습"에 동의했는지? 음성 복제·TTS 사용은 금지인지?
- [ ] **가격 구조**: 시간당 가격인지 일괄 가격인지? 스타트업·학생 할인이나 일부(특정 연령대 화자만)만 사는 것이 되는지?
- [ ] **맞춤 수집 견적**: 20~30대 화자 N명 × 자연 대화 × 감정 라벨(발화당 평가자 3명 이상)의 단가와 기간은?

**AI Hub**
- [ ] 학습한 모델을 상용 서비스에 쓸 때 출처 표기만 하면 되는지(NIA 문의)
- [ ] "이용신청" 데이터(71615·71616)의 승인 기준과 걸리는 기간
- [ ] 동아리(법인 아님)도 신청할 수 있는지, 신청자 개인 명의 사용 범위
