# I. AI Hub 데이터 용량표 (한벗 후보 데이터)

> 조사일: 2026-11-06 · 근거: 각 데이터 AI Hub 상세 페이지(`view.do?dataSetSn=`)와 같은 페이지의 "파일 목록" 데이터(`aJaxS3FileList.do`)를 직접 조회함
> 원본 목록: `데이터셋 조사/hanbeot_datasets.md` · 감정 라벨 비교: `EF_텍스트단위_감정분류.md`

## 한 줄 결론

> 💬 **한 줄:** 6종 전부는 약 **3.05TB**라 처음엔 약 **110GB**만 골라 받음

- **전체:** 핵심 6종 압축 파일만 약 **3.05TB**
- **쏠림:** 이 중 **2.44TB(80%)**가 고령자 구술(71703) 하나
- **나머지 5종:** 합쳐서 약 **625GB**
- **텍스트:** 공감형 대화·멀티세션은 둘 합쳐도 **1GB 미만**
- **권장:** 처음엔 Validation 폴더 + 필요한 키워드 파일만, 약 **110GB**
- **구성:** 음성 데이터의 99% 이상이 wav 원천데이터, 라벨(json)은 데이터당 1.5GB 이하

<details>
<summary>용량 읽는 법</summary>

- **단위:** AI Hub "용량"은 바이트를 1024로 나눈 값(엄밀히는 GiB/TiB)
  - 이 문서의 GB도 같은 기준
  - 1,000 기준 GB로 바꾸면 약 7% 커짐 (예: 302.96GB → 325.3GB)
- **빈칸 주의:** "용량" 칸은 JavaScript로 채워져 단순 텍스트 수집(WebFetch 등)으론 빈칸임
  - 이 문서는 페이지 소스의 `s3FileSize`와 파일별 크기 합계로 확인함 → 둘 다 일치
- **압축 기준:** 모두 zip 기준임
  - wav는 압축이 거의 안 됨 → **푸는 중엔 zip + 해제본으로 약 2배 공간** 필요
</details>

### 4-3. 일부만 받는 방법

- **신청:** 데이터 단위로 **다운로드 신청 → 승인** 후 받음
  - 승인 뒤 "파일 목록" 탭에서 폴더·파일을 골라 받을 수 있음
- **폴더 구조:** 신형 데이터(71631·107·71703·71305·71630 등)는 `Training / Validation × 원천데이터(TS·VS) / 라벨링데이터(TL·VL)`
  - 라벨링 zip이 아주 작음 → **라벨 먼저 받아 분포 확인 → 원천 고르기**가 효율적
- **분할 압축:** 페이지 안내 "API 다운로드 파일은 분할 압축되어 다운로드"
  - `find "폴더" -name "파일명.zip.part*" -print0 | sort -zt'.' -k2V | xargs -0 cat > "파일명.zip"`으로 합친 뒤 풂
  - 페이지 표기: **리눅스 권장, 윈도우는 WSL 필요**
  - 대용량은 "AI 허브 Shell 다운로드"(aihubshell)로 서버에서 받는 게 편함
- **끊김 주의:** 큰 zip 하나가 20~70GB → 끊기면 다시 받아야 함
  - 유선 연결·서버 다운로드 권장

### 4-4. 이용 조건 (모든 데이터 공통)

- **내국인만:** 모든 페이지에 **"※ 내국인만 데이터 신청이 가능합니다."**
  - 팀원 개인 명의(내국인)로 신청해야 함
- **재배포 금지:** 이용정책상 **재배포 금지, 해외 반출·외국 법인은 별도 합의**
  - 원본을 공유 드라이브·GitHub·Hugging Face에 올리면 안 됨
  - 원문을 해외 API(Claude 등)에 넣는 것도 NIA 확인 전엔 피함 (기존 노트와 같음)
- 안심존 4종(71401·565·217·71783)은 다운로드가 아예 없고 IRB 서류가 필요함.
- 71703에는 구술자 **우울·불안 점수**가 있어 민감정보 취급에 주의해야 함.

## 5. 확인 필요

- **71631·71632 시간 불일치**: 통계 "총 3,000시간" vs 메타 표 "6,000시간". 두 데이터(성인+청소년) 합이 6,000시간일 가능성이 있음.
- **71703 용량 불일치**: 본문 "원천 전체 3.81TB, 라벨 653.30MB" vs 실제 파일 목록 2.44TB(원천) / 0.49GB(라벨)
  - 연령·성별 분포는 이미지라 수치를 확인하지 못함
- **263**: 총 시간, 화자 수, 연령대, 구축 연도가 페이지에 없음
  - "건"이 발화인지 대화인지 불분명함
  - 노인 화자 비율은 csv를 받아 봐야 앎
- **466 라벨 체계**: 같은 페이지에 두 개의 7감정 체계가 함께 있음. 실제 json의 Emotion 값을 열어 확인해야 함.
- **86 음성**: 본문엔 음성 1만(또는 15,700) 문장이 있다고 하지만 파일 목록은 텍스트 약 20MB뿐임. 음성 제공 여부는 문의해야 함.
- **71806 심리상담**: 기존 노트는 "안심존 전용", 이번 페이지엔 안심존 표시 없음
  - 개방 파일(73MB, zip 150개)이 있음
  - 1,661시간 mp3가 73MB일 수 없음 → 공개분은 텍스트 위주로 보임
  - 2025-05-16 "비공개 파일 삭제" 이력 있음
- **107**: "구축량 432만"의 단위와 샘플링 레이트가 페이지에 없음.
- **58 멀티모달**: 감정 라벨명이 페이지 텍스트에 없음. 기존 노트의 "8감정 + A/V 1~10"은 이번에 확인하지 못함.
- **71401**: 구축량 9,000 vs 분포표 합계 6,000명 (기존 노트와 같은 불일치).
- AI Hub로 학습한 모델을 상용 서비스에 넣을 수 있는 범위는 여전히 NIA 문의가 필요함.
