# J2. 음성·텍스트 가중치 근거 보강

> 작성일: 2026-11-06 · 계기: "근거 제대로 찾아봐" (J 노트의 0.7/0.3 · 0.3/0.7 · 0.6/0.4에 대한 질문)
> 대상: 한벗 (RTZR STT → 텍스트 감정 / emotion2vec+ 9감정 → 결합 → Claude)
> J 노트(`J_음성텍스트_가중치.md`)에서 이미 확인한 Atmaja·Akagi 2021, Kim·Yi·Won 2024, Pepino 2020, Li 2024는 **다시 풀지 않고** 비교용으로만 씀.
> 검증 표시: 🟢 원문 표를 직접 열어 확인 · 🟡 원문은 봤으나 표 배치가 깨져 해석에 주의 · 🔴 초록/2차 출처만

## 한 줄 결론

> 💬 **정서가 0.7:0.3은 상한선 쪽이고, 각성 0.3:0.7은 텍스트를 너무 많이 줌. 범주 0.6:0.4는 대체로 맞지만 0.5~0.55가 근거에 더 가까움**

- **정서가 (텍스트:음성):** 0.7:0.3 → **0.65:0.35로 조정 권고** (근거 범위 0.55~0.69)
  - 최신 SSL 음성 모델 + 트랜스포머 텍스트에서 **실제로 찾아낸 최적 가중치는 텍스트 0.55 (MSP-Podcast), 0.69 (프랑스 콜센터)** 였음
  - 한국어라 emotion2vec+가 "말 내용"을 몰래 배우는 효과를 기대하기 어려움 → 영어 결과(0.55)보다 텍스트를 조금 더 줌
- **각성:** 0.3:0.7 → **0.1:0.9 권고** (근거 범위 0.0~0.2)
  - 최신 모델 실험에서 텍스트 최적 가중치가 **0** 이었음 (TalTech, Odyssey 2024)
  - 텍스트를 붙이면 각성이 오히려 **떨어진** 결과가 반복됨 (Wagner 2023: −.023~−.065 CCC)
  - 0.3 근거였던 Atmaja 2021의 텍스트 각성 .382는 **대본 데이터(IEMOCAP)의 텍스트 누수** 영향 가능성이 큼
- **5감정 범주:** 0.6:0.4 → **0.55:0.45 권고** (근거 범위 0.45~0.6)
  - 8감정 자연 발화에서 최적 텍스트 가중치 **0.45** (TalTech)
  - 점수 크기를 맞춘 뒤엔 **0.5:0.5와 최적 가중치의 차이가 0.1~1%p** 수준 (Padi 2022, HyFusER 2025)
  - → 범주는 "가중치 숫자"보다 **보정(온도·정규화)이 더 중요**함
- **STT 오류:** WER 약 12%까지는 텍스트 손해 거의 없음. WER 약 40%면 텍스트 단독 약 10%p 하락 → **WER 구간별로 텍스트 가중치를 깎는 규칙** 유지

## 2. 축별 근거 등급

### 정서가 — 🟡 중간 (방향은 강함, 숫자는 중간)

- **방향 (텍스트 ≥ 음성): 🟢 강함**
  - 자연 발화 + SSL에서도 텍스트가 음성과 같거나 높음: BERT .563 vs HuBERT-L .547 (K2), CamemBERT .799 vs wav2vec .730 (K3)
  - 결합하면 크게 오름: .547 → .690 (K2), .730 → .825 (K3), .6295 → .6771 (K1)
  - 한국어 실제 발화에서도 텍스트 우위 15%p (Kim·Yi·Won). 단 연구 대상(독거 고령자)이 한벗 대상(대학생)과 다름 → 참고용
- **숫자 (0.7): 🟡 중간**
  - 직접 찾은 최적값은 **0.55 (K1)**, **0.69 (K3)** → 0.7은 범위의 **위쪽 끝**
  - K1은 텍스트·음성 단독 성능이 비슷(.593 vs .630)했을 때 0.55, K3는 텍스트가 .07 높았을 때 0.69 → **단독 성능 차이가 클수록 텍스트 가중치가 커짐**
- **반대 근거**
  - 영어 최상위 SSL 모델(hubert-L, w2v2-L-robust)은 텍스트를 붙여도 정서가가 **오히려 소폭 하락** (K4: −.042, −.025) → 음성 모델이 이미 말 내용을 "엿들음"(K5: 합성 음성에서 V .386)
  - MSP-IMPROV에선 텍스트 정서가가 음성과 비슷하거나 낮음 (.192 vs .206) — 대본 문장이 고정된 데이터 특성

### 각성 — 🟢 강함 (단, **현재 0.3이 아니라 더 낮춰야 한다는 쪽으로** 강함)

- 텍스트 단독 각성이 음성의 절반 이하: .317 vs .752 (K2 MSP-Podcast), .27 vs .57 (K1)
- 텍스트를 붙여도 각성 이득이 거의 없음: .752 → .765 (+.013, K2), .663 → .668 (K2 IEMOCAP)
- **격자 탐색 최적 텍스트 가중치 = 0** (K1), 텍스트 연결 시 각성 **전부 하락** −.023~−.065 (K4)
- 0.3을 지지하던 Atmaja IEMOCAP 텍스트 각성 .382는 IEMOCAP 대본 누수 영향을 받을 수 있음 (Pepino·Wagner가 경고). MSP-IMPROV에서는 텍스트 각성 .189로 낮음

### 5감정 범주 — 🟡 중간

- 최적 텍스트 가중치 **0.45** (K1, 8감정 자연 발화, ASR 전사)
- SSL 음성이 텍스트보다 약간 높음: WavLM-L .32 vs RoBERTa .27 (K8)
- 한국어 데이터에선 텍스트가 높음: 59.22 vs 51.85 (KEMDy), 70.38 vs 56.38 (AI Hub) (K7) — 단, **화자 분리 아님**, 음성 모델이 약한 CNN
- **가중치보다 보정이 중요:** 점수 정규화 후 0.5:0.5 = 76.07, 원점수 최적 가중치 = 75.97 (K6). 가중 평균 61.00 vs 단순 평균 60.85 (K7)
- → 0.6이든 0.55든 차이가 작을 가능성이 큼. **온도 보정을 먼저** 하는 J 노트 설계가 맞음

**왜 정서가를 영어 최적값(0.55)보다 높게 두나**

- 영어에서 SSL 음성 모델의 정서가가 좋은 이유는 **말 내용을 암묵적으로 배웠기 때문** (K4 4.3절, K5)
  - 이 효과는 **트랜스포머 층을 감정 데이터로 미세조정할 때만** 생김: 고정(frz) 모델은 합성 음성 정서가 .015 (K5)
  - **다국어 모델은 이 효과가 약해서** 텍스트를 붙일 때 이득이 큼: w2v2-L-xls-r +.176, w2v2-L-vox +.103 (K4)
- emotion2vec+는 미세조정된 모델이지만 **한국어 감정 데이터로 학습했는지 확인 안 됨** (모델 카드에 언어 목록 없음)
  - → 한국어에서는 "말 내용 엿듣기"를 기대하기 어려움 → **옛 음향 특징처럼 행동할 가능성** → 텍스트를 영어 SSL 결과보다 더 줌

**STT 오류가 클 때 (J 노트 4-3 STT 규칙 구체화)**

| 추정 WER | 텍스트 가중치 조정 | 근거 |
|---|---|---|
| ≤ 15% | 그대로 | K9: WER 약 12%면 정답 전사와 차이 미미, MSP-Podcast WER 15.02% 전사가 정답 전사와 동급(.616 vs .613) |
| 15 ~ 30% | × 0.75 | 설계값 (K9 곡선의 중간) |
| ≥ 30% (또는 STT 신뢰도 < 0.6) | × 0.5 | K9: WER 약 40%에서 텍스트 단독 약 10%p 하락, 결합하면 약 4%p만 하락 |

- 정서가 0.65 × 0.5 → 재정규화 시 약 **0.48 : 0.52** → STT가 나쁘면 정서가도 음성과 반반이 됨
- 각성은 원래 텍스트 비중이 작아 STT 규칙 영향이 거의 없음
- **대학생 사용자 발화의 RTZR WER을 먼저 재야** 이 표를 쓸 수 있음

**음성 모델이 SSL(emotion2vec+)일 때 vs 옛 음향 특징일 때**

| | 옛 음향 특징 (Atmaja 2021 등) | 최신 SSL (K1·K2·K4) | 한벗 (emotion2vec+ · 한국어) |
|---|---|---|---|
| 정서가 음성 성능 | 텍스트의 절반 (.204 vs .405) | 텍스트와 비슷 (.547 vs .563) | **중간 추정** (한국어 말 내용 학습 불확실) |
| 정서가 텍스트 가중치 | 0.7 안팎 | 0.55 | **0.65** |
| 각성 텍스트 가중치 | 0.3~0.4 | 0 ~ 0.1 | **0.1** |
| 범주 텍스트 가중치 | 0.5~0.6 | 0.45 | **0.55** (한국어 텍스트 우위 반영) |

> ⚠️ **각성의 별도 문제**
> - emotion2vec+는 범주 확률만 내므로 각성은 "범주 → 원형값" 변환으로 얻음 (J 4-1). 이 변환된 각성의 품질은 **어떤 논문으로도 확인 안 됨**
> - 위 각성 근거들은 **차원 회귀 모델**의 결과임 → 한벗 각성에 그대로 옮기려면 KEMDy20 각성 라벨로 CCC를 직접 재야 함
> - 그래도 "텍스트는 각성에 거의 도움이 안 된다"는 결론은 모델 종류와 무관하게 일관됨

## 4. 의사코드 변경분 (J 노트 4-6 대비)

```python
BASE_W = {                      # (w_text, w_audio) 시작값 — J2 근거로 수정
    "valence":  (0.65, 0.35),   # 기존 0.7/0.3  (K1 0.55, K3 0.69)
    "arousal":  (0.10, 0.90),   # 기존 0.3/0.7  (K1 최적 0, K4 텍스트 추가 시 하락)
    "category": (0.55, 0.45),   # 기존 0.6/0.4  (K1 0.45, K7 한국어 텍스트 우위)
}

def stt_factor(wer_est, stt_conf):
    if (stt_conf is not None and stt_conf < 0.6) or (wer_est is not None and wer_est >= 0.30):
        return 0.5
    if wer_est is not None and wer_est > 0.15:
        return 0.75
    return 1.0
```

- 최종 가중치 자르기(0.15~0.85)는 **각성만 0.05~0.95**로 넓힘 (0.1이 0.15로 끌려 올라가지 않게)

## 5. 격자 탐색 범위 수정 (J 노트 5장)

| 매개변수 | 기존 탐색 | **수정 탐색** |
|---|---|---|
| 정서가 w_text | 0.5 ~ 0.9 | **0.4 ~ 0.8** (0.05 간격) |
| 각성 w_audio | 0.5 ~ 0.9 | **0.7 ~ 1.0** (0.05 간격) |
| 범주 w_text | 0.3 ~ 0.8 | 0.3 ~ 0.7 (0.05 간격) |

- K1·K3처럼 **0.05 이하 간격의 격자 + 화자 분리 검증셋**에서 고르는 방식이 학계 표준과 같음
- 범주는 가중치 격자보다 **온도 보정 유무(E4)의 차이**를 먼저 확인할 것 (K6)

## 6. 확인 필요

- 🔴 **emotion2vec+ 학습 언어**: 모델 카드에 언어 목록 없음. 한국어 감정 데이터가 들어갔는지 → 정서가 텍스트 가중치를 0.55로 내릴지 0.65로 둘지 결정 요인
- 🔴 **RTZR의 대학생 사용자 발화 WER**: STT 규칙 구간(15%, 30%)을 쓰려면 실제 WER 측정 필요
- 🟡 **K6 Padi 2022**: 식(1)은 `w1·S_speech`, 본문은 "w1 = 텍스트 가중치"라고 써서 0.94가 어느 쪽인지 모호. 음성 단독 UA는 표 배치가 깨져 64~66 범위로만 기록함. 학회(Odyssey 2022)는 arXiv 메타데이터에 없어 미확인
- 🔴 **K9 Li 2024 Table 1·2**: 그림으로 들어가 있어 ASR별 칸 수치(MSP-Podcast 정서가 CCC vs WER)는 못 봄. 본문 서술과 Table 3만 확인
- 🔴 **K7 HyFusER**: 가중 평균 앙상블에 쓴 가중치 값 미보고, 무작위 분할(같은 화자가 학습·시험 양쪽에 있을 수 있음)
- 🔴 **한국어 AI Hub HuBERT/RoBERTa 논문** (koreascience CFKO202422572711205): HuBERT 87.56 / RoBERTa 91.88 / 결합 92.90으로 보이나 한글 글꼴이 깨져 행 이름·데이터 조건을 확인 못 해 표에서 제외함
- 🔴 **COLD Fusion (Tellamekala)**: 음성·영상 결합이라 음성·텍스트 가중치 근거로는 안 씀
- 못 찾음: **한국어 데이터에서 음성·텍스트 결합 가중치 α를 직접 격자 탐색한 논문**, **emotion2vec 계열 + 텍스트 결합 가중치 논문**
- 판단: 위 권고값도 **영어·프랑스어 자연 발화 근거 + 한국어 정확도 근거를 조합한 설계값**임. KEMDy20(화자 분리) + RTZR 실제 전사로 E3 격자 탐색 후 확정해야 함
