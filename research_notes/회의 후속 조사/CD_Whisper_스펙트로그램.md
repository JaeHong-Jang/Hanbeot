# C·D 후속 조사: Whisper 감정 인식 / 스펙트로그램 기반 SER

- 작성일: 2026-11-06
- 목적: 회의에서 나온 질문 2가지에 답함. "Whisper를 감정 인식에 쓰면 어떤가?", "스펙트로그램을 CNN으로 분류하는 방식은 어떤가?" 그리고 팀 기준인 **정확도 70~80%가 실제 대화에서 가능한가**.
- 기존 노트와 겹치는 논문(EmoBox, SER Evals, Wagner 2023, Park 2024 KsponSpeech CER, 손·권 2024 VGG16)은 숫자만 한 줄로 다시 쓰고 자세한 설명은 `한벗 논문 보강/` 폴더 노트를 참고하도록 함.
- 확인 등급: **A** = 원문(초록·본문 표)에서 직접 확인, **B** = 초록만 또는 2차 요약 경유, **확인 필요** = 숫자를 못 찾았거나 해석이 애매함.

---

## 먼저 결론 3줄

1. **Whisper: 영어에선 강하지만, 한국어 감정 근거는 없음**
   - 영어 벤치마크에서 WavLM보다 **2~4%p** 높고, 처음 보는 데이터에서도 가장 덜 무너짐
   - 다만 한국어 감정으로 평가한 논문은 이번에도 찾지 못함
   - → emotion2vec+를 **바꾸기보다 비교 후보로 추가**하는 게 맞음
2. **스펙트로그램 + CNN: 작고 빠르지만 한벗 주 모델로는 부적합**
   - 모델이 작음(**0.9MB** 수준)
   - 같은 조건에서 자기지도 모델보다 낮고, 다른 데이터로 가면 더 약함
   - → 기기 안에서 도는 보조 신호(예: 울음·한숨, 흥분도 감지)로만 검토할 만함
3. **70~80%는 연기 데이터·4감정 영어 벤치마크에서 나오는 숫자임**
   - 한국 독거노인 실제 발화 연구(D7): 음성만 6감정 **51.4%**, 3감정 **64.7%**
   - 텍스트를 먼저 쓰는 2단계 방식: **69.3%**
   - → 한벗 목표는 "3분류(긍정·부정·중립) + 텍스트 결합 + 한국어 미세조정" 조건에서 70% 정도로 다시 정의하는 게 현실적

# C. Whisper를 감정 인식에 쓰기

## 한 줄 결론

- Whisper 인코더는 현재 공개 SER 벤치마크에서 가장 강한 백본(기반 모델) 중 하나
  - IEMOCAP UA 약 **73%**, 교차코퍼스 1위가 가장 많음
- 하지만 **한국어 감정 결과는 없음**
- 그대로 얼려서(frozen) 쓰면 층 선택에 따라 성능이 크게 떨어짐
  - → LoRA 같은 가벼운 미세조정이 사실상 필요

## 쉬운 개념 설명

- **Whisper**: OpenAI가 68만 시간의 다국어 음성으로 학습한 받아쓰기(ASR) 모델
  - 구조 = 인코더(소리를 숫자 벡터로 요약) + 디코더(벡터를 글자로 바꿈)
- **Whisper를 감정 인식에 쓰는 법**: 디코더는 버리고 **인코더 출력만 꺼냄**
  - 그 위에 작은 분류기(풀링 + 선형층)를 붙임
  - 인코더가 이미 목소리의 높낮이·속도·음색 정보를 많이 담음 → 감정 분류에도 잘 먹힘
- **층(layer) 선택**: 인코더는 여러 층으로 되어 있음
  - 앞쪽 층 = 소리 자체(음색·잡음) / 뒤쪽 층 = 말의 내용에 가까운 정보
  - 감정은 중간~뒤쪽 층에서 잘 나오는 경우가 많음
  - 언어·데이터마다 최적 층이 다름(C2)
- **frozen vs LoRA**
  - frozen: 인코더를 고정하고 분류기만 학습
  - LoRA: 인코더 안에 작은 보정 행렬만 추가로 학습 → 적은 GPU로 미세조정 효과
- **UA / WA**
  - UA(Unweighted Accuracy, = UAR): 감정별 정확도를 단순 평균한 값
  - 데이터가 적은 감정(예: 분노)도 똑같이 반영 → 불균형 데이터에서는 UA가 더 정직함
  - WA: 전체 정답 비율
- **CER**: 글자 오류율. 낮을수록 좋음
  - 한국어 받아쓰기는 단어 띄어쓰기 문제 때문에 WER 대신 CER을 씀

## 각 논문 요약

### C1. EmoBox · 2024

> **한 줄:** 32개 데이터에서 여러 모델을 같은 조건으로 비교했더니 Whisper가 가장 강했음

- **비고:** 기존 노트 ⑧과 같음
- **결과:** 32개 데이터 중 **23개**에서 Whisper-large-v3 인코더가 1위
- IEMOCAP UA **73.54** vs WavLM-large 69.47 → 약 **4%p** 높음
- 처음 보는 데이터(교차코퍼스) 평균: Whisper **52.0%** > WavLM 44.5%
- **눈여겨볼 점:** emotion2vec은 이 비교에 직접 들어가지 않았고 한국어도 없음

### C2. Shendabadi 외 · 2026

> **한 줄:** 작은 Whisper(Tiny·Small)로도 큰 모델에 가까운 감정 인식 성능을 냄

- **어떻게:** Whisper Tiny·Small 인코더 + 주의 풀링
  - 주의 풀링 = 중요한 시간 구간에 가중치를 주는 요약 방법
- **결과:** Small(인코더 약 **88M**) IEMOCAP UA **72.96** → Whisper-large-v3(73.54)에 근접
- 페르시아어 ShEMO: WavLM-L(UA 71.72)보다 **11%p** 높음
- **눈여겨볼 점:** 비영어 데이터에서는 마지막 층보다 **중간 층(Small 12층 중 8층)**이 더 좋음
- **확인 필요:** 프리프린트이고 표끼리 숫자가 일부 섞여 있음(층·풀링 혼합 기재) → 재확인 필요

### C3. Ma·Sang·Li · 2025, ICASSP 2026

> **한 줄:** Whisper를 그냥 얼려 쓰면 약하고, 살짝 미세조정(LoRA)해야 제 성능이 나옴

- **어떻게:** IEMOCAP 4감정, 화자 독립 10-fold
- **결과:** 얼려서 마지막 출력만 쓰면 UAR **0.43~0.58**
- LoRA로 살짝 미세조정하면 **0.77**까지 상승
- **눈여겨볼 점:** EmoBox의 frozen Whisper 73%는 여러 층을 가중 평균하는 다운스트림을 썼기 때문으로 보임(추정)
  - → "Whisper 인코더를 그냥 꽂으면 된다"가 아님. **층 선택·LoRA가 성능을 좌우함**

### C4. Goron 외 · 2024, ICASSP

> **한 줄:** 여러 데이터를 섞어 학습해 처음 보는 데이터에도 버티게 만든 연구

- **어떻게:** 연기·비연기 6개 데이터로 도메인 일반화(처음 보는 환경에도 통하게) 시도
- **결과:** 평균 UAR **74.5%**
- **눈여겨볼 점:** Whisper가 HuBERT·WavLM보다 강한 이유를 논의함
- **확인 필요:** 원문이 IEEE 유료라 초록 수준만 확인(B)

### C5. Whisper-AT · 2023, Interspeech

> **한 줄:** Whisper 하나로 받아쓰기와 함께 울음·웃음 같은 소리 이벤트도 뽑는 방법

- **발견:** "Whisper는 잡음에 강하다"는 통념과 달리 → 인코더 표현은 배경 소리 종류를 강하게 담고 있음
- **어떻게:** 이 점을 이용해 연산 **1% 미만**으로 AudioSet **527종** 소리 이벤트를 같이 뽑음
- AudioSet에는 울음·흐느낌·한숨·웃음 같은 클래스가 있음(클래스 목록 기준)
- **한벗에게:** **감정 라벨 외에 '울음·한숨' 같은 이벤트 신호**를 싸게 얻는 길

### C6. SenseVoice · 2024

> **한 줄:** 한 모델이 받아쓰기·감정·소리 이벤트를 한꺼번에 내는 Whisper 대안

- **어떻게:** Whisper류의 "하나의 모델이 받아쓰기 + 감정 + 이벤트" 구조
- **결과:** Small 모델이 Whisper-Small보다 약 **7배** 빠름
- **눈여겨볼 점:** 한국어 받아쓰기는 지원
  - 하지만 감정 평가는 중국어·영어 7개 데이터만 했고 emotion2vec과 직접 비교하지 않음
- **확인 필요:** 데이터별 SER 숫자는 표 추출이 깨져 미확인

### C7. Lee 외 · 2026

> **한 줄:** 한국 75세 이상 어르신 음성으로 Whisper 받아쓰기를 학습·보강한 연구

- **어떻게:** 한국 75세 이상 화자 **104명**의 VOTE400으로 Whisper 학습
- **결과:** 모델이 클수록 글자 오류율(CER)이 낮음 → Small **12.5** → Large-v3 **5.5**
- 학습 데이터를 늘리면(증강) **2.7**까지 하락
  - LLM으로 노인 말투 문장 생성 + 노인 목소리 TTS로 합성
- **확인 필요:** 기준선 행이 "제로샷"인지 "원본 데이터 미세조정"인지 논문이 명시하지 않음
- **확인 필요:** 테스트 화자가 학습 화자와 겹치는지도 안 밝힘

### C8. Park 외 · 2024

> **한 줄:** 일반 성인 한국어 자유대화에서 Whisper 받아쓰기 오류율을 잰 연구

- **비고:** 기존 노트와 같음
- **결과:** KsponSpeech(일반 성인 자유대화) 제로샷 CER **14~17%**
- **주의:** C7의 노인 CER 5.5와 직접 비교하면 안 됨 (데이터 성격·평가 조건이 다름)

## 한벗에 적용하면

1. **emotion2vec+를 Whisper로 "교체"할 근거는 아직 없음**
   - Whisper 우위 근거는 모두 영어·유럽어 벤치마크
   - emotion2vec+와 Whisper를 같은 조건에서 비교한 결과도 없음(C1, 기존 노트)
   - 다음 단계: 한국어 벤치마크(KEMDy19/20, AI Hub, 화자 독립)에서 3개를 같이 돌려보기
   - 비교 대상: **emotion2vec+ / Whisper-small 인코더+LoRA / SenseVoice-Small**
2. **Whisper는 Small(인코더 88M)부터 시작**할 만함
   - C2에서 Small이 Large와 **1%p 이내** → 비용·지연은 훨씬 작음
   - 단, **frozen + 마지막 층만**은 피하고 층 가중합 또는 LoRA를 써야 함(C3)
3. **STT는 RTZR 유지**
   - Whisper는 기본적으로 스트리밍이 아님
   - 한국어 자유대화 제로샷 CER **14%** 수준(C8)
   - 노인 음성 미세조정 시 CER 3~6%까지 내려간다는 결과(C7)는 고무적 → 하지만 실시간 대화 조건이 아님
4. **"ASR+SER 한 번에" 아이디어**
   - SenseVoice(C6)나 Whisper-AT식 헤드(C5)로 실험 가능
   - 특히 울음·한숨 이벤트 감지는 감정 4라벨보다 오히려 위기 신호로 쓸모가 클 수 있음
5. **잡음 주의**
   - Whisper 표현이 배경 소리와 상관이 큼(C5) → 노인 가정의 TV·라디오 소리가 감정 판단을 흔들 수 있음
   - 한국 독거노인 실제 녹음 연구(D7)도 TV·라디오 잡음 녹음을 걸러내야 했음

## 확인 필요 항목 (C)

- C2: 표 1·2의 일부 숫자가 서로 다른 층·풀링 결과를 섞어 기재됨. 인용 전 원문 표 4 대조.
- C3: EmoBox의 frozen Whisper(73.5%)와 C3의 frozen(43~58%) 차이가 다운스트림 구조 차이 때문인지 원문 확인 필요(현재는 추정).
- C4: 6개 데이터 이름, 데이터별 UAR, 평가 프로토콜(화자 독립 여부) — IEEE 원문 필요.
- C6: SenseVoice 표 8의 데이터별 SER 수치, 가중치 라이선스.
- C7: 기준선이 제로샷인지, 테스트 화자 분리 여부. VOTE400이 낭독체인지 대화체인지.
- Oh·Kim·Park (2023, 말소리와 음성과학 15(3), ETRI) "대형 사전훈련 모델의 파인튜닝을 통한 강건한 한국어 음성인식 모델 구축": 1,000시간 한국어로 Whisper 미세조정 시 CER 크게 개선, 영어 성능 저하라고 초록에 있으나 **수치 확인 필요** ([KoreaScience](https://koreascience.kr/article/JAKO202330043250854.page)).
- van Dijk 외 (2025, EMNLP HCINLP 워크숍) 네덜란드 노인 ASR: "범용 다국어 모델이 노인 특화 미세조정 모델보다 좋았다"는 초록 결론만 확인, **수치 확인 필요** ([arXiv 2508.08684](https://arxiv.org/abs/2508.08684)).
- Whisper(또는 emotion2vec+)를 **한국어 감정**으로 평가한 논문: 이번에도 찾지 못함("없다"가 아니라 "못 찾음").

# D. 스펙트로그램 기반 SER

## 한 줄 결론

- 스펙트로그램(또는 MFCC) + CNN은 **모델이 아주 작고 빠름**
- 하지만 같은 IEMOCAP 4감정에서 자기지도 모델(WavLM 등)과 비슷하거나 낮음
  - 특히 **라벨 데이터가 적거나 처음 보는 데이터일수록 차이가 커짐**
- 한국어 스펙트로그램 연구의 **80~90%대** 숫자는 대부분 연기 데이터·무작위 분할 결과
  - → 한벗 실제 대화 성능의 근거가 되지 못함

## 쉬운 개념 설명

- **스펙트로그램**: 소리를 그림으로 바꾼 것
  - 가로 = 시간, 세로 = 주파수(높낮이), 밝기 = 세기
- **멜(mel) 스펙트로그램 / log-mel**: 사람 귀처럼 낮은 소리는 촘촘히, 높은 소리는 듬성듬성 나눈 스펙트로그램
  - 로그를 취해 큰 소리·작은 소리 차이를 줄임
  - **FBANK**도 거의 같은 말
- **MFCC**: 멜 스펙트로그램을 한 번 더 압축해 음색의 윤곽만 남긴 숫자 13~40개
  - 옛날부터 쓰던 대표 음성 특징
- **CNN / CRNN / ResNet / VGG**: 그림 분류용 신경망 → 스펙트로그램을 그림처럼 읽음
  - CRNN = CNN 뒤에 LSTM(시간 순서를 읽는 신경망)을 붙인 것
- **AST(Audio Spectrogram Transformer)**: 스펙트로그램을 작은 조각(패치)으로 잘라 트랜스포머로 읽는 모델
  - 원래 AudioSet(소리 이벤트) 분류용
- **자기지도 모델(wav2vec2·HuBERT·WavLM·emotion2vec)과의 차이**
  - 스펙트로그램 CNN: **감정 라벨이 붙은 데이터만으로 처음부터** 배움
  - 자기지도 모델: 라벨 없는 음성 수만~수십만 시간으로 "소리 보는 눈"을 미리 길러 둠
  - 자기지도 모델은 감정 라벨을 마지막 단계에만 조금 씀
  - → 한국어 감정 데이터처럼 **라벨이 적을 때** 자기지도 쪽이 훨씬 유리함

## 각 논문 요약

### D1. WavLM 논문의 SUPERB 표 · 2022

> **한 줄:** 같은 분류기에 입력만 바꿔 보니, 스펙트로그램은 자기지도 특징의 절반 수준

- **어떻게:** SUPERB = "모델 본체는 얼리고 같은 가벼운 분류기만 학습"하는 공정 비교 규칙
- **결과(IEMOCAP 4감정):** log-mel(FBANK) 그대로 **35.39%** vs WavLM Large 특징 **70.62%**
- **눈여겨볼 점:** **라벨 데이터가 적고 분류기가 작을 때** → 자기지도 특징의 이점이 2배 가까이 됨
- **확인 필요:** 표의 열 이름이 추출 과정에서 깨져 있어 열 위치로 감정 열을 추정함

### D2. Satt 외 · 2017, Interspeech

> **한 줄:** 스펙트로그램을 바로 CNN·LSTM에 넣는 방식의 고전 논문

- **결과:** IEMOCAP 4감정 약 **68%**
- 이후 연구들은 표에서 UA **62.0** / WA **67.3**(즉흥 부분)으로 인용
- **눈여겨볼 점:** 현재 자기지도(SSL) 계열(70~74%)보다 낮음

### D3. Light-SERNet · 2022, ICASSP

> **한 줄:** 1MB도 안 되는 아주 작은 감정 인식 모델

- **어떻게:** MFCC 입력, 모델 크기 **0.88MB**
- **결과:** IEMOCAP UA 약 **70.8%** → 크기 대비 성능은 최고 수준
- **눈여겨볼 점:** TFLite 버전이 공개돼 있어 **휴대폰 안에서 돌리기 쉬움**
- **주의:** 평가가 10-fold 교차검증이고 화자 분리 여부를 밝히지 않음
  - → 같은 화자가 학습·테스트에 섞이면 숫자가 부풀려짐(기존 노트 `ser_limits_papers.md` 참고)

### D4. Shayaninasab·Babaali · 2024

> **한 줄:** 크게 사전학습한 모델이라면 스펙트로그램이든 원음이든 성능이 거의 같음

- **어떻게:** 같은 페르시아어 데이터에서 AST(스펙트로그램 트랜스포머)와 wav2vec2를 둘 다 미세조정
- **결과:** **79.3%** vs **80.0%**로 거의 같음
- **눈여겨볼 점:** AST도 AudioSet으로 사전학습된 큰 모델 → "작은 CNN"과는 다름
  - → **스펙트로그램이냐 원음이냐보다 "대규모 사전학습을 했느냐"가 핵심**
- **확인 필요:** 분할 1회 결과, 프리프린트

### D5. Wagner 외 · 2023, TPAMI

> **한 줄:** 트랜스포머 모델이 스펙트로그램 CNN보다 작은 교란(잡음 등)에 더 강함

- **비고:** 기존 노트와 같음
- **결과:** 트랜스포머 모델이 스펙트로그램 CNN 기준선보다 **작은 교란에 더 강건**
- **한벗에게:** 녹음 기기·환경이 제각각인 노인 가정에서는 이 강건성이 중요함

### D6. 윤상혁 외 · 2021, ACK

> **한 줄:** 국내의 전형적인 멜 스펙트로그램 CRNN 연구 (숫자가 높게 나오는 조건의 예)

- **어떻게:** 국내 학부·대학원 수준의 전형적인 멜 스펙트로그램 CRNN
- **결과:** 연기 DB 6감정 **88.89%**
- **주의:** 테스트가 **90개**뿐이고 화자 분리 없이 무작위로 나눔
- **눈여겨볼 점:** 국내 스펙트로그램 논문의 "80~90%대" 숫자는 대부분 이런 조건

### D7. Kim·Yi·Won · 2024

> **한 줄:** 혼자 사는 어르신의 실제 대화로 감정 인식을 해 본, 한벗과 가장 가까운 한국 연구

- **위치:** 스펙트로그램 단독 연구는 아님(wav2vec2 + CNN-LSTM) → 한벗 기준을 판단할 가장 중요한 한국 논문
- **데이터:** 혼자 사는 65~96세 **133명**이 아이 모습 컴패니언 로봇에게 3개월간 말한 실제 녹음
- 감정 불균형(중립 38%, 분노 3%) / 사람끼리 라벨 일치도도 **0.70**에 그침
- **결과(음성만):** 6감정 **51%**, 3감정 **65%**가 한계
- **결과(2단계):** 텍스트로 먼저 긍정·부정·중립을 나눔 → 음성으로 세부 감정 선택 → **69%**로 가장 높음
- **저자 언급:** "실험실 모델(80~95%)과 달리 실제 환경 데이터라 낮다"

### D8. 손귀영·권순일 · 2024

> **한 줄:** 자유발화 음성을 그림(스펙트로그램)으로 바꿔 이미지 분류 모델로 감정을 맞힌 연구

- **비고:** 기존 노트 K③
- **어떻게:** AI Hub 자유발화 → 스펙트로그램 이미지 → VGG16으로 분류
- **결과:** 성인 **83.5%**
- **확인 필요:** 자유발화인데 높은 이유가 화자 분리 부재 때문인지 확인되지 않음

## 한벗에 적용하면

1. **주 모델 교체는 비추천**
   - 스펙트로그램 CNN은 한국어 감정 라벨이 많이 필요함
   - 처음 보는 사용자·녹음 환경에서 더 약함
   - → 사용자마다 휴대폰·방 환경이 다른 한벗 같은 서비스와 맞지 않음
2. **보조 용도로는 쓸 만함**
   - Light-SERNet급(1MB 미만) 모델을 휴대폰에 올림
   - "목소리 흥분도(arousal) 높음/낮음"이나 "울음 소리 있음" 같은 **2분류 경보**만 맡김
   - → 원음을 서버로 보내지 않고도 위기 신호를 잡는 구조 → 개인정보 측면에서 장점
3. **팀 내 비교 실험의 하한선(baseline)으로 넣기**
   - log-mel + 작은 CNN을 같은 한국어 분할로 돌려 둠
   - → emotion2vec+가 "얼마나 더 나은지"를 숫자로 보여줄 수 있음(심사 대응용으로 좋음)

## 70~80%는 실제 대화에서 가능한가 (C·D 공통)

| 조건 | 대표 숫자 | 출처 |
|---|---|---|
| 영어 연기 데이터, 4감정, 화자 분리 | UA 70~77% | C1·C2·C3 |
| 한국어 연기 DB, 무작위 분할 | 83~89% | D6·D8 |
| 처음 보는 데이터(교차코퍼스) | Whisper 평균 52%, macro-F1 0.13~0.20 | C1, SER Evals |
| **한국 독거노인 실제 발화, 음성만** | **6감정 51.4%, 3감정 64.7%** | D7 |
| **같은 데이터, 텍스트→음성 2단계** | **6감정 69.3%** | D7 |

- **결론: 음성만으로 실제 노인 대화에서 4~6감정 70~80%는 근거가 없음.**
  - 가장 가까운 한국 연구도 음성만으로는 65% 이하
- **70% 근처가 현실적인 조건**
  - ① 3분류(긍정·부정·중립) 또는 흥분도 2~3단계
  - ② Claude가 보는 **텍스트와 결합**
  - ③ 한국어 실제 대화 데이터로 미세조정
  - ④ 화자 독립 분할로 측정
- **지표:** "정확도" 하나보다 **UA + 부정 감정 재현율(놓치지 않는 비율)**로 정하는 게 맞음
  - 독거노인 데이터는 중립이 38% → 정확도만 보면 중립만 찍어도 숫자가 나옴(D7 분포 기준)

## 확인 필요 항목 (D)

- D1: SUPERB 표에서 35.39 / 70.62가 감정(ER) 열이라는 것은 열 위치로 추정한 값. WavLM 원문 표 대조 필요.
- D2: 원문 수치(66%/68%)와 후속 논문 인용치(UA 62.0/WA 67.3, 68.8%)가 다름. 원문 PDF 표 확인 필요.
- D3: Light-SERNet의 10-fold가 화자 독립인지 미기재. 정식 ICASSP 2022 게재본(DOI 10.1109/ICASSP43922.2022.9746679)과 수치 일치 여부.
- D4: 단일 분할 결과. AST가 어떤 사전학습 체크포인트였는지.
- D5: CNN14 기준선의 구체 수치는 초록에 없음.
- D7: 화자 독립 분할 여부, 음성 단독 모델에 스펙트로그램 CNN을 별도로 비교했는지는 원문에서 못 찾음.
- AST를 IEMOCAP에 직접 미세조정한 동료심사 논문 수치: 이번 검색에서 못 찾음.
- 한국어 데이터에서 **스펙트로그램 CNN vs wav2vec2/emotion2vec을 같은 분할로 비교**한 논문: 못 찾음. 서강대 학위논문(HuBERT 4감정 0.8139)은 기존 노트에 있음.
