# 한벗 구현 계획 — P0 기능 → 모듈 → 주차 → 검증

작성 2026-11-07. 설계서 2절(P0/P1/P2)·8절(7주 일정)·8.3(중단 기준)을 하네스 모듈에 대응시킨 표다. 오늘은 W2(11/03–11/09) 끝 무렵이고, 11/9 회의에서 감정 체계·기억 구조·위험도 결합 규칙이 정해진다. 그 전까지 해당 항목은 **미확정**으로 두고 인터페이스만 고정한다.

## 0. 지금 상태와 첫 일주일

| 항목 | 상태 |
|---|---|
| 설계서·논문 근거·Wiki | 완료 (설계서 10.1.1 P1~P101, Wiki 513페이지) |
| 하네스 폴더·규약 | 이 문서와 함께 생성 |
| 코드 | 골격만. 통화 루프 E2E는 아직 없음 → W2 목표가 밀렸으므로 **W3 전반에 통화 루프를 먼저 끝낸다** |
| 11/9 회의 결정 대기 | 감정 체계(평가용 4·서비스용 5+판정보류), 기억 3층 구조·기억 에이전트, 위기 위험도 = max(텍스트, 음성), 타깃(대학생 vs 고령층 — 회의 후속 조사 노트의 비교 조건이 고령층) |

첫 일주일(11/10–11/16) 순서.
1. `scripts/dev-up.sh`로 Postgres+pgvector 기동, 마이그레이션 0001 적용, `apps/api` health 응답.
2. 통화 루프 최소 경로: `vad_turn → stt_rtzr → context_builder → llm_claude → tts_typecast`. SER·KeywordGate·RiskTag는 **통과(pass-through) 프로세서**로 자리만 잡는다.
3. `apps/web` 통화 화면: 연결·마이크·끄기·자막. TTFA 끝점(첫 오디오 재생)을 이벤트로 보낸다.
4. 10분 통화 1회 성공 + TTFA 로그 10턴 → 7.2절 정의대로 P50 보고.
5. 그 다음에야 domain 규칙(§2 표)을 채운다.

## 2. domain 규칙 구현 순서 (표 → 함수 → 테스트)

| 순서 | 함수 | 입력·출력 | 미확정 여부 | 테스트 케이스 수 |
|---|---|---|---|---|
| 1 | `consent.allowed_features(c) -> frozenset[Feature]` | 3단 bool → 기능 집합 | 확정 (5⑩ 8조합표) | 8 |
| 2 | `consent.on_withdraw(prev, new) -> list[StopAction]` | 변경 전후 → 중단 목록 | 확정 | 4 |
| 3 | `crisis.step(state, signals) -> tuple[State, Action]` | 키워드·태그·사용자 정정 → 다음 상태·행동 | 전이표 확정, **max 결합 미확정** | 12 |
| 4 | `memory.transition(state, event) -> State` | stated/inferred/confirmed/approved | 확정 | 10 |
| 5 | `memory.context_window(turns, n)` | 직전 n턴 | **n 미확정(6~10)** | 4 |
| 6 | `emotion.map_label(label)` | 9라벨 → 제품 범주 | **체계 미확정(4/5감정)** → 매핑표를 데이터로 분리 | 9 |
| 7 | `emotion.should_ask(cue, state)` | 점수·5턴·동의·안전 모드 | 임계 0.6은 보정 전 "순위용" | 8 |
| 8 | `emotion.detect_mismatch(voice, text)` | 긍정 텍스트 + 부정 음성 | **미확정(J)** | 4 |
| 9 | `usage.should_notify(elapsed, state)` | 60분·주 6일 임시 기준 | 임시 | 4 |
| 10 | `modes.system_prompt(mode, cues, memory_block)` | 3모드 + 단서 + 기억 | 확정 | 3 |

미확정 항목은 **값을 설정 파일(`app/domain/rules.yaml`)로 빼서** 회의 결정 후 숫자만 바꾼다. 함수 시그니처는 바꾸지 않는다.
