# 감정 인식 계획 — 무엇을 분류하고, 어디까지 되고, 어떻게 사람처럼 들리게 하나

작성 2026-11-08. 근거: `research_notes/회의 후속 조사/` A(원리·턴), BC(라벨 기준·복합 감정), DE(Whisper), FG(텍스트 단위·분류 체계), H·H2(음성·텍스트 가중치), IJ(맥락·개인화), `reports/한벗 기술 논문 근거.md` §1 ④, Wiki `topic-ser-label-scheme-and-fusion`, `claim-app-9`. 11/9 회의 결정 전 항목은 **미확정**.

## 0. 한 줄 답

**AI는 감정을 "이해"하지 않는다.** 소리와 글의 패턴을 보고 "사람들이 이런 패턴에 슬픔이라고 붙였다"를 확률로 돌려줄 뿐이다. 그래서 한벗은 "네 감정을 안다"고 주장하는 제품이 아니라, **"이렇게 들렸는데 맞아?"라고 묻는 제품**으로 설계한다. 이 전제를 지키면 감정 인식의 한계가 제품의 약점이 아니라 대화 방식이 된다.

## 1. 어디까지 되나 (숫자로)

| 조건 | 성능 | 출처 |
|---|---|---|
| 영어 연기 음성(IEMOCAP) 4감정, 최고 모델 | UA 약 76% | 논문 근거 P29 |
| 학습한 데이터 밖 코퍼스로 옮기면 | macro-F1 0.67~0.78 → 0.13~0.20 | P21 (B) |
| 한국어 공개 수치 | AI Hub HuBERT 4감정 정확도 0.81 1건, 분할 조건 미확인 | P26 |
| 한국어 **실제 대화**, 음성만 | 6감정 51.4%, 3감정 64.7% | Kim·Yi·Won 2024 (고령자 표본, 참고 상한) |
| 같은 데이터, 텍스트 먼저 → 음성으로 세부 | 6감정 69.3% | 같음 |
| 사람끼리 라벨 일치도 | κ 0.27~0.48, 약 18%는 합의 실패 | IEMOCAP, MSP-Podcast |
| 사람이 음성만으로 14감정 맞히는 비율 | 약 50% | Banse & Scherer 1996, 남경식·민경환 2001 |

결론: **"목소리만으로 70~80%"는 근거가 없다.** 사람도 목소리만으로는 절반이다. 현실적 목표는 **3감정 + 텍스트 결합으로 약 70%**, 지표는 UA와 부정 감정 재현율. emotion2vec+는 한국어로 학습·평가된 기록이 없으므로 한국어 대학생 발화 성능은 W3 자체 평가 전까지 **모른다**고 말한다.

## 2. 무엇을 분류하나 (라벨 체계, 미확정)

세 층으로 나눈다. 모델이 내는 것, 평가에 쓰는 것, 사용자에게 보이는 것은 다르다.

| 층 | 내용 | 이유 |
|---|---|---|
| 모델 출력 | emotion2vec+ 9라벨 softmax 확률 + 정서가(좋다–나쁘다)·각성(차분–흥분) 점수 | 모델이 주는 그대로. 버리지 않고 다음 층이 고른다 |
| 평가용 | **4감정**: 분노·기쁨·중립·슬픔 (화자 분리 평가, UA·클래스별 재현율·혼동행렬) | 공개 벤치마크·AI Hub 4감정과 비교 가능 |
| 서비스용 | **5감정 + 판정보류**: 답답함(분노), 밝음(기쁨), 가라앉음(슬픔), **불안**, 중립, 그리고 1·2위 확률이 비슷하면 **판정보류** | 묶을수록 정확도가 오른다(27분류 .46 → 6분류 .64 → 4그룹 .69). 불안은 대학생 고민에서 빈번. 판정보류는 "틀린 단정"을 막는 장치 |
| 축 점수 | 긍정–부정, 흥분도 | **외로움·우울은 각성이 가장 낮아(외롭다 각성 1.97) 범주 분류가 "중립"으로 놓친다.** 저각성 부정은 축 점수로만 잡힌다 |

범주 밖 라벨(fearful, disgusted, surprised, other, unknown)은 질문에 쓰지 않는다. 사용자에게 보이는 말은 라벨 직역("너 슬프구나")이 아니라 들린 그대로("목소리가 좀 가라앉은 것 같은데")다.

## 3. 음성과 글을 어떻게 합치나 (미확정 H)

핵심 사실: **글은 좋다–나쁘다에 강하고, 목소리는 들뜸–가라앉음에 강하다.** IEMOCAP 화자 분리에서 정서가 CCC 텍스트 0.405 vs 음성 0.204, 각성 CCC 음성 0.543 vs 텍스트 0.382.

1. **2단계**: Claude(텍스트)가 먼저 긍정/부정/중립을 가르고, 그 안에서 음성이 세부(가라앉음·답답함·불안)와 강도를 고른다. 한국어 실제 대화에서 가장 높았던 방식(69.3%).
2. **축별 가중치(시작값)**: 정서가 글 0.65 : 목소리 0.35, 각성 글 0.1 : 목소리 0.9, 5감정 글 0.55 : 목소리 0.45. 논문에서 추론한 시작값이라 KEMDy20·AI Hub로 화자 분리 5겹 실험 후 조정.
3. **불일치는 따로 본다**: "괜찮아"(글 긍정) + 가라앉은 목소리(음성 부정)를 평균 내면 중립 0.49로 사라진다. 평균 대신 불일치를 검출해 **되묻는다**. 빈도는 3턴에 1번, 10턴에 2번까지(미확정).
4. **위기 위험도 = max(텍스트, 음성)**: 음성은 위험도를 올리기만 하고 내리지 못한다(미확정).
5. **확률은 보정 뒤에만 확률이다**: 모달리티별 온도 보정 1개. 보정 전 0.6은 "60% 맞다"가 아니라 순위용. W3에 ECE 측정.

## 4. 맥락과 개인화 (미확정 IJ)

- 직전 **6~10턴**(사용자+한벗 합쳐, 왕복 3~5회)을 화자 표시와 함께 Claude에 넘긴다. 5~12턴에서 성능이 포화하고 그 이상은 떨어진다(IEMOCAP +12.5점). 0/2/6/10턴 비교 실험을 W3에 한 번 한다.
- **개인 기준선**: 같은 사람의 평소 목소리를 기준으로 상대 변화를 본다(기준선 보정 시 긍정/부정 판단 상대 +13.5%). 사용자별 평소 피치·속도·멈춤 평균을 pgvector에 저장하고, 세션 초반 3턴 또는 30초 미만에는 상대 지표를 쓰지 않는다.
- 첫 턴·새 사용자는 기준선이 없으므로 음성 단서를 꺼 두고 텍스트만 쓴다.

## 5. 대화가 사람처럼 들리게 하는 것 (감정 인식과 별개로 되는 것)

감정을 "맞히는" 것보다 **"듣고 있다"가 전달되는 것**이 체감을 좌우한다. 이건 지금 기술로 된다.

| 기법 | 내용 | 근거 |
|---|---|---|
| 확인 질문 | 단정 대신 "~한 것 같은데, 맞아?" 한 문장, 응답 끝에 | 설계서 5④-2 |
| 응답 속도 | 첫 소리까지 1~1.5초. 사람 턴 간격은 약 0.2초, ChatGPT 음성은 약 1.4초 | P15·P16·P18 |
| 끼어들기 | 사용자가 말하면 300ms 안에 멈춤. "응/음" 백채널에는 멈추지 않음 | P0-2 |
| 맞장구 | 3~4초 이상 말하다 쉬고 Smart Turn이 "아직"이라 하면 작은 "응" 클립 | VAP, CABP(한국어) |
| 필러 | Claude 첫 토큰이 0.7초 넘게 늦을 때만 "음, 그러니까…", 연속 사용 금지 | Filler-Speech(EMNLP 2025) |
| TTS 억양 | 직전 2~3턴을 `previous_text`로 넘겨 맥락에 맞는 억양, 속도 0.9~0.95, 사용자 감정이 가라앉았으면 밝게 말하지 않음 | TTS 조사 PART 4 |
| 기억 | "지난주 팀원 얘기는 어떻게 됐어?"처럼 직전 세션을 이어 받음. 저장은 허락받은 것만 | claim-app-4 |

## 6. 검증 계획 (언제, 무엇으로, 합격선)

| 주 | 실험 | 데이터 | 지표·합격선 |
|---|---|---|---|
| W3 (11/10~16) | emotion2vec+ 한국어 4감정 기준 성능 | AI Hub 감정 음성(약관 OK 시) 화자 분리 분할 dev/calib/test | UA ≥ 0.70 합격, 0.80 목표. 분노 재현율 별도 보고 |
| W3 | 보정 | calib 세트 | ECE, 신뢰도 곡선. 0.6 임계값 재설정 |
| W3 | emotion2vec+ vs Whisper 인코더+LoRA 1회 비교 | 같은 분할 | UA 차이. Whisper는 IEMOCAP 43~77%로 설정에 크게 좌우됨 |
| W3 | 맥락 턴 수 0/2/6/10 | ESConv 한국어 번역 또는 팀 대화 | 텍스트 감정 F1 |
| W4 | 음성·텍스트 결합 가중치 | KEMDy20·AI Hub 화자 분리 5겹 | 5감정 UA, 부정 재현율, 불일치 검출 정밀도 |
| W4 | Opus 코덱 전후, 성별 분리, 발화 길이 구간 | 같은 세트 | 저하 폭 보고, 모델 카드 작성 |
| W6 | 사용자 테스트 핵심 비교 1개 | 대학생 20~30명, 1인 3세션 | SER 기반 확인 질문 vs 같은 빈도의 일반 확인 질문. 수용률·침해감·재사용 의향 |

표본: 정확도 0.70에서 95% 구간 반폭은 n=100 ±9.0, n=200 ±6.4, n=400 ±4.5(독립 이항 근사, 화자 군집이면 더 넓음). 평가 발화 **200개 이상, 화자 10명 이상**.

## 7. 중단 기준

- W3 말 UA < 0.70 또는 SER 결과가 턴 마감 전에 도착하는 비율 < 50% → SER을 P2로 내리고, 확인 질문은 **속도·멈춤 단서만**으로 하거나 끈다. 제품은 텍스트 감정(Claude)만으로도 동작한다.
- 분노 재현율이 확인되지 않으면 "답답함" 질문은 끈다(자연 대화에서 Emotion2Vec 분노 F1 0.000 사례).
- emotion2vec+ 가중치 상업 이용이 불가로 확정되면 SenseVoice-Small 또는 Whisper+LoRA 자체 학습으로 간다.
