# 감정 인식 계획 — 무엇을 분류하고, 어디까지 되고, 어떻게 사람처럼 들리게 하나

작성 2026-11-08. 근거: `research_notes/회의 후속 조사/` A(원리·턴), BC(라벨 기준·복합 감정), DE(Whisper), FG(텍스트 단위·분류 체계), H·H2(음성·텍스트 가중치), IJ(맥락·개인화), `reports/한벗 기술 논문 근거.md` §1 ④, Wiki `topic-ser-label-scheme-and-fusion`, `claim-app-9`. 11/9 회의 결정 전 항목은 **미확정**.

## 0. 한 줄 답

**AI는 감정을 "이해"하지 않는다.** 소리와 글의 패턴을 보고 "사람들이 이런 패턴에 슬픔이라고 붙였다"를 확률로 돌려줄 뿐이다. 그래서 한벗은 "네 감정을 안다"고 주장하는 제품이 아니라, **"이렇게 들렸는데 맞아?"라고 묻는 제품**으로 설계한다. 이 전제를 지키면 감정 인식의 한계가 제품의 약점이 아니라 대화 방식이 된다.

## 1. 어디까지 되나 (숫자로)

| 조건 | 성능 | 출처 |
|---|---|---|
| 영어 연기 음성(IEMOCAP) 4감정, 최고 모델 | UA 약 76% | 논문 근거 P29 |
| 학습한 데이터 밖 코퍼스로 옮기면 | macro-F1 0.67~0.78 → 0.13~0.20 | P21 (B) |
| 한국어 공개 수치 | AI Hub HuBERT 4감정 정확도 0.81 1건, 분할 조건 미확인 | P26 |
| 한국어 **실제 대화**, 음성만 | 6감정 51.4%, 3감정 64.7% | Kim·Yi·Won 2024 (고령자 표본, 참고 상한) |
| 같은 데이터, 텍스트 먼저 → 음성으로 세부 | 6감정 69.3% | 같음 |
| 사람끼리 라벨 일치도 | κ 0.27~0.48, 약 18%는 합의 실패 | IEMOCAP, MSP-Podcast |
| 사람이 음성만으로 14감정 맞히는 비율 | 약 50% | Banse & Scherer 1996, 남경식·민경환 2001 |

결론: **"목소리만으로 70~80%"는 근거가 없다.** 사람도 목소리만으로는 절반이다. 현실적 목표는 **3감정 + 텍스트 결합으로 약 70%**, 지표는 UA와 부정 감정 재현율. emotion2vec+는 한국어로 학습·평가된 기록이 없으므로 한국어 대학생 발화 성능은 W3 자체 평가 전까지 **모른다**고 말한다.

## 2. 무엇을 분류하나 (라벨 체계, 미확정)

세 층으로 나눈다. 모델이 내는 것, 평가에 쓰는 것, 사용자에게 보이는 것은 다르다.

| 층 | 내용 | 이유 |
|---|---|---|
| 모델 출력 | emotion2vec+ 9라벨 softmax 확률 + 정서가(좋다–나쁘다)·각성(차분–흥분) 점수 | 모델이 주는 그대로. 버리지 않고 다음 층이 고른다 |
| 평가용 | **4감정**: 분노·기쁨·중립·슬픔 (화자 분리 평가, UA·클래스별 재현율·혼동행렬) | 공개 벤치마크·AI Hub 4감정과 비교 가능 |
| 서비스용 | **5감정 + 판정보류**: 답답함(분노), 밝음(기쁨), 가라앉음(슬픔), **불안**, 중립, 그리고 1·2위 확률이 비슷하면 **판정보류** | 묶을수록 정확도가 오른다(GoEmotions 27감정+중립 .46 → Ekman 6+중립 .64 → 4감성 그룹 .69). 불안은 대학생 고민에서 빈번. 판정보류는 "틀린 단정"을 막는 장치 |
| 축 점수 | 긍정–부정, 흥분도 | **외로움·우울은 각성이 가장 낮아(외롭다 각성 1.97) 범주 분류가 "중립"으로 놓친다.** 저각성 부정은 축 점수로만 잡힌다 |

범주 밖 라벨(fearful, disgusted, surprised, other, unknown)은 질문에 쓰지 않는다. 사용자에게 보이는 말은 라벨 직역("너 슬프구나")이 아니라 들린 그대로("목소리가 좀 가라앉은 것 같은데")다.

### 2-1. 감정 개수는 늘리지 않는다 (2026-11-08, Scopus 1,818편 초록 분석 결과, 검증 중)

"6감정 이상으로 늘려야 하지 않나"에 대한 답은 **아니다**이다. 근거는 `research_notes/Scopus 조사/02_labels_calibration_fusion_unist.md`.

| 근거 | 수치 (초록 기준) | 출처 |
|---|---|---|
| 클래스를 늘려서 좋아진 연구는 1,214편 초록 중 없음. 반대 사례만 있음 | SSL 음성 모델이 이진 감성 WA 81%·UA 73%, 6감정·3/7클래스 감성에서는 실패 | Atmaja & Sasou 2022, 10.3390/s22176369 |
| 데이터 성격이 클래스 수보다 결과를 더 좌우 | 같은 논문 안에서 RAVDESS 8클래스(연기) 71.6%, EMO-DB 7클래스(연기) 86.1%, IEMOCAP 4클래스(화자 독립) 64.3% | Issa 외 2020, 10.1016/j.bspc.2020.101894 |
| **불확실하면 답을 보류**하는 것이 가장 확실한 이득 | 불확실도 상위 25% 거부 시 정서가 CCC 상대 +13.7%, 각성 +7.3%; 커버리지 60%에서 정서가 +16.9% | Sridhar & Busso 2020·2021 |
| 라벨 하나 대신 **분포**로 학습 | 소프트 라벨 UWA +6.8%(IEMOCAP), +2.7%(MSP-Podcast); 복합 감정 허용 +7.1~8.4% | Kumawat & Routray 2025; ESWA 2024 |
| 음성 단독으로 "불안"을 잡은 근거 없음 | 생체신호 연구에서도 EEG 외에는 우연 수준 | UNIST Kim S.P. 2020 |

그래서 v2는 이렇게 바꾼다.
- **평가용**: 4감정 유지 + 정서가·각성 3단계(low/mid/high) + 발화당 평가자 3명 이상의 **분포** + 판정보류 커버리지-위험 곡선. 늘리는 건 클래스가 아니라 축과 분포다.
- **제품용**: 5감정 + 판정보류 + 2축 유지. 단 **불안은 글(Claude) 우선 라벨**로 내리고 음성은 "각성↑·정서가↓" 보조만 한다. **가라앉음은 범주가 아니라 축 조건**(정서가 낮음 AND 각성 낮음 AND 개인 기준선 대비 지속 변화)으로 정의한다. 판정보류는 1·2위 근접만이 아니라 보정 신뢰도·엔트로피·글-소리 불일치를 합친 불확실도로 정하고, 시작값은 보류 약 25%.
- **6번째 이후 라벨**은 내부 로그에만 남기고 질문에 쓰지 않는다.
- **논문용**: 새 7클래스 체계가 아니라 "한국어 자연 대화 + 보정(ECE) + 보류 곡선 + 확인 질문 수용률"이 기여점이다. 7클래스를 새로 제안하면 비교 대상이 없어 약하다.

확인 질문 규칙 v2 (근거는 같은 노트 §7.5):

| 상황 | 조건 | 말하는 방식 |
|---|---|---|
| 일치·확신 | 보정 신뢰도 높음, 글·소리 방향 일치 | 묻지 않거나 가볍게 되받음 |
| 불일치 | 글 긍정 + 소리 가라앉음(또는 반대) | "괜찮다고 했는데 목소리는 좀 가라앉은 것 같아. 맞아?" |
| 판정보류 | 신뢰도 낮음 | **라벨을 말하지 않고** 열린 질문 ("오늘은 어땠어?") |
| 저각성 부정 | 축 조건 + 개인 기준선 대비 지속 | 부드러운 체크인. "우울"·"외로움" 단어 금지. **주의**: 인용된 우울·외로움 음성 연구는 임상 환자 대 대조군 또는 고령 표본이라, 일반 대학생에서의 오탐률은 미지수다(검증자 지적) |
| 위기 | 텍스트 위기 단서 (max 규칙) | 위기 흐름(claim-app-10) |

## 3. 음성과 글을 어떻게 합치나 (미확정 H)

핵심 사실: **글은 좋다–나쁘다에 강하고, 목소리는 들뜸–가라앉음에 강하다.** IEMOCAP 화자 분리에서 정서가 CCC 텍스트 0.405 vs 음성 0.204, 각성 CCC 음성 0.543 vs 텍스트 0.382.

1. **2단계**: Claude(텍스트)가 먼저 긍정/부정/중립을 가르고, 그 안에서 음성이 세부(가라앉음·답답함·불안)와 강도를 고른다. 한국어 실제 대화에서 가장 높았던 방식(69.3%).
2. **축별 가중치(시작값)**: 정서가 글 0.65 : 목소리 0.35, 각성 글 0.1 : 목소리 0.9, 5감정 글 0.55 : 목소리 0.45. 논문에서 추론한 시작값이라 KEMDy20·AI Hub로 화자 분리 5겹 실험 후 조정.
3. **불일치는 따로 본다**: "괜찮아"(글 긍정) + 가라앉은 목소리(음성 부정)를 평균 내면 중립 0.49로 사라진다. 평균 대신 불일치를 검출해 **되묻는다**. 빈도는 3턴에 1번, 10턴에 2번까지(미확정).
4. **위기 위험도 = max(텍스트, 음성)**: 음성은 위험도를 올리기만 하고 내리지 못한다(미확정).
5. **확률은 보정 뒤에만 확률이다**: 모달리티별 온도 보정 1개. 보정 전 0.6은 "60% 맞다"가 아니라 순위용. W3에 ECE 측정.

## 3-1. 전처리는 감정을 분류하지 않는다 (2026-11-08, Scopus 분석, 검증 중)

"분노·기쁨·슬픔을 전처리 단계에서 어떻게 분류시키나"에 대한 답: **전처리는 분류하지 않는다.** 전처리는 입력을 표준화하고 방해 요인을 줄이는 단계이고, 분류는 SSL 인코더(emotion2vec+/HuBERT/WavLM/Whisper)와 그 위의 작은 헤드가 한다. 그래서 성능을 올리는 지점은 전처리 "규칙"이 아니라 ① 발화 단위를 어떻게 자르나 ② 어떤 특징을 어떻게 모으나 ③ 소음을 어디서 처리하나 ④ 사람마다 기준선을 어떻게 잡나 ⑤ 라벨을 어떻게 쌓나 다섯 가지다. 근거는 `research_notes/Scopus 조사/01_preprocessing_models_crosscorpus.md`(257편 읽음).

## 4. 맥락과 개인화 (미확정 IJ)

- 직전 **6~10턴**(사용자+한벗 합쳐, 왕복 3~5회)을 화자 표시와 함께 Claude에 넘긴다. 5~12턴에서 성능이 포화하고 그 이상은 떨어진다(IEMOCAP +12.5점). 0/2/6/10턴 비교 실험을 W3에 한 번 한다.
- **개인 기준선**: 같은 사람의 평소 목소리를 기준으로 상대 변화를 본다(기준선 보정 시 긍정/부정 판단 상대 +13.5%). 사용자별 평소 피치·속도·멈춤 평균을 pgvector에 저장하고, 세션 초반 3턴 또는 30초 미만에는 상대 지표를 쓰지 않는다.
- 첫 턴·새 사용자는 기준선이 없으므로 음성 단서를 꺼 두고 텍스트만 쓴다.

## 5. 대화가 사람처럼 들리게 하는 것 (감정 인식과 별개로 되는 것)

감정을 "맞히는" 것보다 **"듣고 있다"가 전달되는 것**이 체감을 좌우한다. 이건 지금 기술로 된다.

| 기법 | 내용 | 근거 |
|---|---|---|
| 확인 질문 | 단정 대신 "~한 것 같은데, 맞아?" 한 문장, 응답 끝에 | 설계서 5④-2 |
| 응답 속도 | 첫 소리까지 1~1.5초. 사람 턴 간격은 약 0.2초, ChatGPT 음성은 약 1.4초 | P15·P16·P18 |

## 7. 중단 기준

- W3 말 UA < 0.70 또는 SER 결과가 턴 마감 전에 도착하는 비율 < 50% → SER을 P2로 내리고, 확인 질문은 **속도·멈춤 단서만**으로 하거나 끈다. 제품은 텍스트 감정(Claude)만으로도 동작한다.
- 분노 재현율이 확인되지 않으면 "답답함" 질문은 끈다(자연 대화에서 Emotion2Vec 분노 F1 0.000 사례).
- emotion2vec+ 가중치 상업 이용이 불가로 확정되면 SenseVoice-Small 또는 Whisper+LoRA 자체 학습으로 간다.

`reports/한벗 최종 계획 v3.md`가 이 문서의 아래 절을 대체한다. 검증표 7건과 비평 37건(§10)을 반영했다. v3의 규칙은 모두 11/9 회의 상정안이다.

- **§2-1 라벨 체계** → v3 §3.2·§3.9. 구조는 같다. emotion2vec+는 9라벨 확률·임베딩만 내고 **VA 점수는 없다**(별도 회귀 헤드 필요). 제품 5라벨은 모델 라벨의 동의어가 아니라 조작적 정의(§3.9)이고 별도 평가셋으로 검증한다. 서비스에서는 범주 밖 라벨이 상위면 재정규화하지 않고 판정보류. GoEmotions는 28→7→4.
- **§3 결합** → v3 §3.3·§3.9. 실행 순서는 위기 → 입력 품질 → 보류 → 불일치 되물음 → 2단계 결합. 가중치 0.65/0.35·0.1/0.9·0.55/0.45는 설계 가설. 온도 보정은 SER 로짓에만 적용(Claude 극성은 대상 아님), 결합 출력은 별도 세트로 재보정. **위기 위험도 = max(글, 소리)는 철회**하고 위기는 글 기반으로 유지.
- **판정보류** → v3 §3.4. 25% 시작, 위험 함수는 수용 발화의 클래스 균형 오류, 감정별·화자군별 커버리지 보고, 임계값은 calib 세트에서 고정. 확정은 W5 R7.
- **§3-1 전처리 13단계** → v3 §3.5. 즉시 적용 7개(13단계 #1·#3·#6·#10·#12 + 화자 분리 평가), 미확정 8개, 소음·RIR·GAP+SAP는 후보. 짧은 입력은 직전 발화와만 병합. 재현용 화자 LOSO와 제품용 대화쌍·세션 분리를 따로 보고.
