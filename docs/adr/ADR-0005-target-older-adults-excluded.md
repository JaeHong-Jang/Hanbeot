# ADR-0005 고령자를 한벗 대상에서 제외, 1차 타깃 대학생 유지

- 상태: 결정 (2026-11-07 팀 커밋 607f0f5, 2026-11-08 팀장 확인)
- 배경: 11/7 회의 후속 조사 노트 초판은 비교 조건·데이터를 고령층(독거노인 133명 실제 발화 SER, 노인 STT, 고령자 구술 71703)으로 잡아 타깃이 바뀐 것처럼 읽혔다. 팀이 노트·데이터셋·TTS·유사앱 문서에서 고령자 전제를 제거했다.
- 결정: 한벗 대상에서 고령자를 제외한다. 1차 타깃은 대학생(이후 취준생·직장인) 그대로다.
- 영향:
  - 설계서·Wiki·페르소나·시장(TAM/SAM/SOM)·가설 H1~H5·교수님 답변·면접 대본은 그대로 유효하다.
  - SER 참고 수치: 독거노인 133명 연구(음성만 3감정 64.7%, 텍스트 2단계 69.3%)는 "한국어 실제 대화 SER의 현실적 상한" 참고로만 쓴다. 대학생 발화 성능은 W3 자체 평가 전까지 미지수다.
  - 평가 세트 화자는 20대 중심 + 다양성(성별·억양)으로 유지한다.
  - 데이터: AI Hub 고령자 구술(71703)·중노년 방언(71517·71558)은 후보에서 내린다.
- 기록 정정: 2026-11-08 오전에 "고령층 전환" ADR과 Wiki 절이 잘못 작성됐고 같은 날 이 문서로 대체했다.
