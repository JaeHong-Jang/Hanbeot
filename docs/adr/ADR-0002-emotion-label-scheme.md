# ADR-0002 감정 라벨 체계

- 상태: 제안 (11/9 회의 결정 대기)
- 배경: 평가용 4분류(분노·슬픔·기쁨·중립)와 서비스용 5감정(+불안), 판정 보류, 긍정–부정·흥분 점수가 논의 중.
- 현재 기본값: 설계서 5④-1의 4분류. 나머지 emotion2vec+ 라벨(fearful 등)은 질문하지 않는다.
- 구현: `rules.yaml`의 `label_scheme`, `label_map`. `emotion.map_label` 시그니처는 고정.
- 대안: 5감정(불안 추가) + 판정 보류 / 연속값(CCC) 병행.
- 결정 시 할 일: label_map 수정, ml/ser 지표 라벨 집합 변경, 평가 세트 버전 올림.
- 근거: 설계서 5④-1, 구현-계획 §4
