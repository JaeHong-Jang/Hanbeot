# ADR-0004 위기 위험도 = max(텍스트, 음성)

- 상태: 철회 상정 (2026-11-08 v3 §3.3·비평 #7·#8: 위기는 글 기반 유지, 음성은 위기 점수에 넣지 않음. 11/9 회의에서 확정)
- 배경: 텍스트 태그와 음성 저각성 단서를 어떻게 합칠지. 설계서 5⑨-1은 음성 단서만으로 점수가 오르지 않는다고 규정.
- 현재 구현: `crisis.combine_risk`는 max를 계산하지만, `step`은 설계서 규칙(텍스트 L2 + 같은 턴 음성 0.5점)을 따른다. 기본 결합 규칙은 텍스트만(`crisis_combine_rule: text_only`).
- 위험: max를 채택하면 음성 단독 신호가 L1 판정에 영향. 음성이 탐지를 개선하지 않으면 가산을 뺀다(5⑨-1).
- 대안: 텍스트 단독 / 텍스트 + 음성 가산(현행 설계서).
- 결정 시 할 일: `step`에서 combine_risk 사용 여부, 텍스트 단독 vs 결합을 `ml/crisis`에서 비교.
- 근거: 설계서 5⑨, Wiki claim-app-10
