# ADR-0005 1차 타깃을 대학생에서 고령층으로 변경

- 상태: 결정 (2026-11-08, 팀장 확인)
- 배경: Wiki·설계서(2026-10-25)는 1차 타깃을 대학생으로 잡았다. 11/7 회의 후속 조사 노트는 비교 조건과 데이터를 전부 고령층으로 잡았다(독거노인 133명 평균 80.6세 실제 발화 SER, 75세+ 한국어 STT, 고령자 구술 71703, 중·노년 방언 71517·71558). 팀장이 타깃 변경을 확인했다.
- 결정: 1차 타깃 = 고령층(혼자 지내는 고령자 중심). 대학생은 2차 확장 후보로 내린다.
- 영향:
  - 페르소나·온보딩 문구·AI 고지 문구를 고령 사용자 기준으로 다시 쓴다(큰 글자, 짧은 문장, 전화 걸기 중심 UI).
  - 평가 세트 화자 구성을 60대 이상으로 바꾼다. 머뭇거림 녹음, 위기 시나리오, 기억 50문항 모두.
  - SER 목표는 고령 실제 발화 기준으로 다시 잡는다(음성만 3감정 64.7%, 텍스트 결합 2단계 69.3%, Kim·Yi·Won 2024). 저각성 감정(외로움·우울) 미탐 위험이 핵심.
  - STT는 고령 발화·방언 CER을 따로 측정한다. 가장 가까운 선례는 클로바 케어콜(B2G)이며 B2C 차별점을 다시 정의해야 한다.
  - 시장(TAM/SAM/SOM), 가설 H1~H5, 교수님 답변 초안, 면접 대본은 대학생 기준이라 **재작성 대상**이다.
- 아직 정할 것: 연령 하한(60/65), 거주 형태(독거만인지), 채널(앱 vs 전화 수신), 보호자·기관 연계 여부, 결제 주체(본인/가족/지자체).
