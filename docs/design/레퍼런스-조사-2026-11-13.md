# 한벗 화면 레퍼런스 조사 (2026-11-13)

조사 사이트: lapa.ninja, thedieline.com, itsnicethat.com, awwwards.com, cosmos.so, 그리고 실제 앱 사례.
접근 메모: lapa.ninja는 자동 수집을 막아 목록의 제목과 카피만 읽었다. cosmos.so는 열리지만 그림 설명이 없어 컬렉션 이름만 확인했다(브라우저에서 직접 볼 컬렉션: `/design/talking-to-machines`, `/design/love-a-good-home-screen`, `/design/please-wait-loading`). 나머지는 실제로 연 페이지만 적었다.

## 1. 화면별 레퍼런스와 빌릴 점

### (1) 입장 이야기 (3초씩 지나가는 장면)
- The Way Meditation https://www.awwwards.com/sites/the-way-meditation : 스크롤하면 붓자국이 길이 되고 음성이 안내한다. 빌릴 것: 장면을 끊지 않고 하나의 선(빛)으로 이어 붙이기.
- Benno's Light https://www.awwwards.com/sites/bennos-light : 6챕터 일러스트, '빛'이 챕터 전환 장치. 빌릴 것: 꺼진 방에서 램프가 켜지는 전환.
- I'm having bad dreams https://www.awwwards.com/sites/im-having-bad-dreams : 깨짐, 버팀, 회복의 3막 1인칭 서사.
- When loneliness calls https://www.awwwards.com/sites/when-loneliness-calls : 검은 화면과 글자만으로 전화 거는 순간을 재현.
- Sleep Well Creative https://www.awwwards.com/sites/sleep-well-creative : 크림 #FEF1D0 + 딥블루 #0042AF 두 색, 과학 근거를 그림 서사로.
- Jun Cen https://www.itsnicethat.com/articles/jun-cen-wetransfer-the-new-yorker-illustration-110619 : 뒷모습과 측면으로 얼굴을 다 보여주지 않는 외로움 표현, 저채도 야경.
- Nano, The Lonely People https://www.itsnicethat.com/articles/nano-the-lonely-people-illustration-240519 : 핑크 하늘, 눈 내리는 밤 같은 저채도 밤 장면을 연작으로, 그림마다 짧은 제목.
- Lily Kong, I'm Fine https://itsnicethat.com/articles/lily-kong-illustration-140921 : 엽서가 매개가 되는 이야기, 사건 대신 요소만 떼어 그리는 간접 묘사.
- Welltory 온보딩(Rive) https://contra.com/p/c6ZeRUlr-rive-onboarding-funnel-for-a-mobile-app : 26장을 한 장면이 다음으로 이어지는 연속 서사로.
- Tolan 온보딩 https://screensdesign.com/apps/tolan-alien-best-friend/ : 장면마다 그림 1장 + 문장 1개, 마지막만 "길게 눌러 만나기".

### (2) 로그인, 이름 (환영받는 느낌)
- Finch https://screensdesign.com/articles/finch-app-onboarding-design/ : 알을 고르고 새가 태어난 뒤, 새가 말풍선으로 이름을 묻는다. 빌릴 것: 입력 폼이 아니라 친구가 묻고 내가 답하는 대화형 이름 입력.
- Tolan : 이름 뒤 "Finding your Tolan" 로딩을 만남 연출로. 빌릴 것: 로딩을 "친구가 문 열러 오는 시간"으로.
- Interlude(lapa 목록) https://www.lapa.ninja/post/interludeapp/ : "Presence without performance, connection without capture" 같은 카피 톤.
- Dawn(lapa 목록) https://www.lapa.ninja/post/joindawn/ : 기능 나열 대신 한 문장 약속.

### (3) 홈, 누구와 말할지 고르기
- Sesame https://www.sesame.com/blog/getting-started : 네 명을 상단 피커로 전환, 기억은 각자 분리. 빌릴 것: 카드 목록이 아니라 "지금 집에 있는 사람" 전환.
- Tolan 디자인 노트 https://www.tolans.com/relay/designing-tolan-part-1-characters : 로스터 선택을 버리고 매칭된 한 명 + 색과 머리 조정. 인간형을 피한 이유는 로맨스 롤플레이 유입 방지.
- Sunny's Journey https://www.awwwards.com/sites/sunnys-journey : 공간마다 캐릭터 접점 하나(워키토키). 빌릴 것: 거실, 주방, 베란다 등 자리마다 친구가 있고 그 자리를 탭.
- Cozy Eating Village https://www.awwwards.com/sites/cozy-eating-village : 마을을 돌아다니는 탐험형 홈.

### (4) 통화 화면, 말하는 캐릭터
- Tolan : 전신 캐릭터가 장소 안에 있고 파형은 보조.
- Rive 통화 캐릭터 글 https://dev.to/uianimation/building-duolingo-style-ai-video-call-characters-using-rive-10o9 : Idle, Listening, Thinking, Speaking 상태 + 감정 입력. "듣는 상태(눈맞춤, 끄덕임, 멈칫)"를 말하는 상태보다 먼저 설계.
- A digital cat meditation https://www.awwwards.com/sites/a-digital-cat-meditation : 터치와 소리에 즉시 반응하는 캐릭터.
- 말하는 입 구현 방식(난이도 순):
  1. 음량을 입 벌림 값으로(Live2D 문서 https://docs.live2d.com/en/cubism-sdk-manual/lipsync/ ). 음량 3단계로 닫힘, 반, 열림 프레임 교체. 학생팀 1차 권장.
  2. AE 2.5D 리그를 Lottie 루프로(Finch 사례 https://contra.com/p/seOAX3PZ-expressive-character-animation-for-finch-app ). 말하는 동안 루프 재생, 동기 없음. 1과 병행 가능.
  3. Rive 상태머신 + 비짐(Duolingo https://blog.duolingo.com/world-character-visemes ). 음소 타이밍을 주는 TTS가 있어야 함. 높음.
  4. 3D 절차 애니메이션(Tolan). 전담 애니메이터 필요. 매우 높음.

### (5) 냉장고, 편지 보관함
- Kind Words https://store.steampowered.com/app/1070710 : 편지에 붙인 스티커가 방 장식이 됨. 빌릴 것: 편지 1통 = 자석 1개, 보관함이 곧 꾸며지는 공간.
- 하루콩 https://apps.apple.com/KR/app/id1553223828 : 월간 달력의 표정 콩을 탭하면 그날 기록. 빌릴 것: 자석 격자 = 달력.
- Slowly https://apps.apple.com/au/app/id1199811908 : 거리 기반 배송 지연, 우표 수집.
- Lily Kong(위) : 엽서 교환이라는 매개.

## 2. 색과 글꼴, 그림체
- 크림 또는 흰 바탕 + 깊은 포인트 1색: Sleep Well(#FEF1D0 + #0042AF), MNDFL(#987654 + #DF6C4F, https://www.awwwards.com/sites/mndfl-meditation ), Companion(#FFFFFF + #FF6300, https://www.awwwards.com/sites/companion-a-different-talk ), Virtual Well-being Hub(#F3A632 + #A4A045, 대학생 대상, https://www.awwwards.com/sites/virtual-well-being-hub ). 그라디언트 없이 2~3색, 색은 그림에 맡긴다.
- 글꼴 2단: 친구의 말은 손글씨 느낌 1종, UI는 깔끔한 한글 산세리프 1종(Unmind https://www.itsnicethat.com/news/ragged-edge-unmind-graphic-design-branding-280423 , Moodnotes https://www.itsnicethat.com/features/ustwo-moodnotes-cbt-mental-health-app ).
- 얼굴: 추상과 사실 사이(Stefanie Röhnisch https://www.itsnicethat.com/articles/stefanie-röhnisch-illustration-250122 ), 감정 범위를 허용하고 항상 웃는 얼굴 금지(Headspace https://www.itsnicethat.com/articles/italic-studio-headspace-graphic-design-project-250424 ). 사진이라면 자연광, 플래시 없음, 긴장이 풀린 뒤의 정면 응시(Magnus Holmes, Roommates https://www.itsnicethat.com/articles/magnus-holmes-roommates-photography-170420 ).
- 질감: 크레용(Shiori Tamura https://itsnicethat.com/articles/shiori-tamura-discover-illustration-100123 ), 아크릴 붓질(Nano), 크라프트와 엠보싱(Dieline: Ten Degree Tour https://thedieline.com/ten-degree-tours-packaging-blends-form-and-landscape-for-quiet-rituals/ , Chá De Saudade https://thedieline.com/blog/2021/1/14/-ch-de-saudade ). 손 흔적이 "사람이 만들었다"는 신호.
- 안정감은 어둠과 달과 별이 아니라 빛, 온기, 촉감으로(Gentlee https://thedieline.com/sweet-dreams-start-with-gentlee/ ).

## 3. 피할 것
- 점수와 대시보드 톤(Mira https://www.awwwards.com/sites/miralife-app ): 감정이 숫자로 보이면 헬스테크가 된다.
- 코파일럿형 미니멀(SOL Health https://www.awwwards.com/sites/sol-health ): 틸과 블루와 퍼플, 글로우 오브, 기능 나열.
- 카드 격자 + 이름, 나이, 태그, NEW, 재화, 의상 교체(Larc 류). 좌우 스와이프 선택과 사실적 인간형은 데이팅 앱 연상. 선택지는 2~3명, "누굴 고를까"보다 "누가 지금 깨어 있나".

## 4. 제안 방향 (적용 전 확인용)
1. 입장: 세 장면을 따로 자르지 않고 "꺼진 방 → 복도의 불빛 → 현관문 → 불 켜진 거실"로 카메라가 이어지는 한 흐름. 문장은 장면당 하나. 마지막은 현관문을 길게 눌러 초인종.
2. 로그인: 폼 대신 친구가 문틈으로 "어떻게 부르면 돼?"라고 묻고 내가 답하는 대화형. 이름을 치면 "문 열어 줄게" 로딩이 집에 들어가는 연출.
3. 홈: 친구 카드 목록이 아니라 한 집 안 장면. 소파, 주방, 베란다에 친구가 각자 있고, 그 자리를 탭해서 옆에 앉는다. 선택지는 지금처럼 2명, 많아도 3명.
4. 통화: 듣는 상태(눈맞춤, 끄덕임, 멈칫) 모션을 먼저, 말하는 입은 음량 3단계 프레임 교체로 시작. 파형은 작게 보조.
5. 냉장고: 자석 격자를 달력으로, 편지 1통이 자석 1개가 되어 쌓인다.
6. 색: 지금의 벽지색을 유지하되 포인트는 소파 초록 1색만 남기고, 빨강은 도움과 끊기에만. 그림 3장(입장)은 Nano와 Jun Cen처럼 저채도 밤 장면, 얼굴은 뒷모습과 측면.
