# 한벗 이미지 고도화 프롬프트 (GPT 이미지 생성용)

기준 그림: `apps/web/src/shared/assets/friend-haneul.jpg`, `rooms/living-night.jpg`. 모든 새 그림은 이 두 장과 같은 집, 같은 사람, 같은 조명으로 보여야 한다.

## 0. 먼저 지킬 것 (일관성)

1. 한 대화창에서 만든다. 첫 요청에 기준 그림 두 장을 올리고 "이 사람과 이 집을 기준으로 한다"고 못 박는다.
2. 캐릭터는 먼저 "캐릭터 시트" 한 장(정면, 45도, 옆, 웃음, 무표정)을 뽑고, 그다음 장면을 만든다. 장면마다 그 시트를 다시 올린다.
3. 요청은 영어로 쓰고 한국어 문구는 넣지 않는다(글자 없음). 비율과 크기를 매번 명시한다.
4. 한 번에 한 장씩, 마음에 들면 "같은 설정으로 다음 장면"으로 이어 간다. 바꾸고 싶은 것 하나만 말한다.
5. 받은 뒤 확인: 눈과 머리카락 색, 소파 색(올리브), 스탠드 위치, 창문 모양이 기준 그림과 같은가. 손가락 수, 글자, 로고가 없는가.

공통 스타일 문장(모든 프롬프트 끝에 붙임):

> Style: photorealistic editorial photography, 35mm lens, shallow depth of field, soft tungsten lamp light (2700K) with a cool dusk window as fill, warm low-saturation palette of cream, oatmeal, olive green and walnut brown, gentle film grain, no text, no logos, no watermark, no exaggerated beauty retouching, natural skin texture.

피할 것(필요하면 Negative로 명시):

> Avoid: neon or saturated colors, harsh flash, stock-photo smiles, studio backdrop, text, letters, logos, extra fingers, duplicated faces, glossy 3D render look, anime style.

## 3. 말하는 입 프레임 (통화 화면 립싱크)

친구마다 초상 한 장을 고정하고, 이미지 편집(인페인팅)으로 입 주변만 바꿔 3장: `friend-<id>-mouth-closed.jpg`, `-half.jpg`, `-open.jpg`. 머리, 눈, 배경, 조명은 바뀌면 안 된다.

- 편집 요청(원본을 올리고 입 영역만 선택):
  > Edit only the mouth area. Keep everything else pixel-identical: eyes, hair, hands, background, lighting. Version 1: lips closed in a soft relaxed smile. Version 2: lips slightly parted as if saying "eh", teeth barely visible. Version 3: mouth open a little more as if saying "ah", natural, not exaggerated.
- 확인: 세 장을 빠르게 넘겨 봤을 때 입만 움직이고 얼굴 위치가 흔들리지 않아야 한다. 흔들리면 "do not move the head, change only the lips"를 덧붙여 다시 만든다.
- 코드 연결은 `features/call`에서 `state.orb === 'speaking'`일 때 120~180ms 간격으로 closed, half, open을 소리 크기 순서로 바꾸면 된다. 실제 음성이 붙으면 재생 오디오의 음량(AnalyserNode)으로 프레임을 고른다.
