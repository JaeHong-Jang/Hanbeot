# src-bae-2022-carecall-memory-update

# src-bae-2022-carecall-memory-update

## 서지
Bae et al., "Keep Me Updated! Memory Management in Long-term Conversations", Findings of EMNLP 2022. 네이버 CareCall(돌봄 안부 전화) 한국어 7,665세션. 논문 윤리 절에서 이용자를 취약 집단으로 언급. CareCall 대상 연령은 본문 확인 못 함.

## 수치
- 세션 종료 후 요약 문장 저장 → 새 정보와 비교해 유지·교체·추가·삭제 결정. 분포: 추가 44.6%, 교체 37.0%, 유지 13.3%, 삭제 5.1%.
- 사람 평가 기억도: 갱신 56.59 > 누적 50.31 > 기억 없음 36.37. 5세션째 누적 방식 기억도 -0.67 (갱신 +0.24).

## 한벗 적용
통화 후 기억 에이전트가 PASS/REPLACE/APPEND/DELETE를 정하는 안건 M 제안(미확정)의 근거. 쌓기만 하면 오히려 해가 됨.
