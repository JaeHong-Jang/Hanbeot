# src-noh-2021-mpgln-multidomain

## 서지
Noh K.J. 외 (ETRI), 2021, MPGLN 다중 도메인 적응, Sensors. DOI 10.3390/s21051579. 한국어 KESDy18·KESDy19 + IEMOCAP.

## 수치 (초록 기준)
- 다중 도메인 적응 F1 +3.7%, 도메인 일반화 +3.5%. 비교 기준은 temporal feature generator 기반 모델(VGGish 계열)이며 모든 환경의 평균 보장치가 아니다.

## 검증 결과 (2026-11-08)
- 등급 B (Scopus 초록·공개 논문 색인 대조). 수치 일치.
