# topic-app-schedule-7weeks

상위: [[overview-app-design]] · 설계서 8절. 교수님 피드백 ④ 대응 [[claim-feedback-1-reflect-professor-round1]]. 결정: [[claim-app-7-schedule-gates-and-cuts]]

역할: PM·안전(일정, 인터뷰, 동의·위기 문구, 위기 운영 책임, 약관·연구윤리), FE, BE-음성(Pipecat, STT·TTS·턴, 삭제·격리), AI(SER, 프롬프트, 위험 태그, 메모리, 평가). 공수 가정은 1인 주 약 15시간 x 4명 x 7주 = 약 420인시(추정, W1 확정). P1은 핵심 경로에 여유가 있을 때만.

## 8.1 주차별 표
| 주차 | 기간 | 목표 | 핵심 산출물 | 검증 |
|---|---|---|---|---|
| W1 | 10/27–11/02 | 라이선스·약관 확인, 설계 확정, 문제 인터뷰 시작 | 라이선스 체크리스트 5항목(emotion2vec 가중치, openSMILE, KEMDy·AI Hub, 벤더 학습 금지·국외이전·보존, OSS), Claude 단가, 연구윤리 필요 여부, `simple-chatbot` 구동, 와이어프레임, H1 인터뷰 4~5명 | 체크리스트 5/5, 데모 1회, 인터뷰 기록 |
| W2 | 11/03–11/09 | 음성 루프 E2E | RTZR + Claude + Typecast + Smart Turn + 끼어들기, TTFA 로깅, 통화 화면 v1, TTS 블라인드 비교, H1 인터뷰 나머지 | 10분 통화 성공, **TTFA 1차 측정 → 목표 조정 결정**, H1 1차 판정 |

그라운딩(호흡 1분)은 W5 필수 산출물이 아니다(P1-6).

## 8.2 핵심 경로
W1 키·약관·단가 → W2 통화 루프(P0-1~3) → W3 KeywordGate·위험 태그(P0-6) → W5 안전 모드·동의·운영 → [게이트] → W6. 분기: W3 SER·확인 질문(P0-4, 라이선스 의존), W4 요약·기억·삭제·격리(P0-8~10), 자문 섭외(W3) → 문구 검수(W5), 연구윤리 확인(W1) → 필요 시 신청(W2). 핵심 경로는 통화 루프 → 위기 분류·안전 모드 → 동의·삭제 → 게이트이며, SER·확인 질문과 기억은 축소 가능 범위다.

## 8.3 중단·축소 기준
| 시점 | 조건 | 조치 |
|---|---|---|
| W1 말 | emotion2vec 가중치·데이터 약관 부정 또는 회신 없음 | SER은 교육 목적 비교에만, 부정이면 SER P2 강등, 확인 질문은 속도·멈춤만 또는 끔 |
| W2 말 | H1 인터뷰 반증 신호 | 타깃 재정의, W3 이후 범위를 통화 루프 + 안전 + 요약으로 축소 |
| W2 말 | 10분 통화 루프 미완성 | RTZR WebSocket 직접 구현 또는 대체 STT, W3 SER 작업 중단 |
| W3 말 | 통화 루프 미완성 | **SER을 P2로 강등**, 기억은 "내가 말한 것"만 |
| W3 말 | SER UA < 0.70 또는 적시 도착률 < 50% | SER P2 강등, H3 비교는 "속도·멈춤 단서"로 바꾸거나 취소 |
| W3 말 | 위험 태그 준수율 < 99% | 별도 분류 호출로 전환 |
| W4 말 | 기억 승인·삭제 미완성 | 기억 저장 끄고 "통화 후 요약만" |
| W5 말 | 게이트 미충족 | 외부 테스트 연기·취소, 내부 파일럿과 오프라인 평가로 발표 대체 |
| W2 이후 매주 | TTFA P50이 조정 목표 초과 | 지연 조정 순서([[topic-app-cost-latency-budget]]), W4까지 미달이면 발표에서 미달 보고 |

## 8.4 사용자 테스트 시작 게이트 (일정과 별도, 5개 모두 충족)
1. 위기 평가 세트 기준 통과(P0-6, 테스트 세트 성능이며 안전 보증 아님을 참가 설명서에 기재) → [[topic-app-impl-safety-crisis]]
2. 전문가 문구 검수 완료(안전 스크립트, 109 카드, 요약 금지 목록)
3. 동의 8조합, 통화 중 철회, 삭제(설계 저장소), 사용자 격리 테스트 통과 → [[topic-app-impl-consent-privacy]]
4. 연구윤리 절차(필요 시) 완료
5. 위기 운영 표와 참가 설명서 확정

## 8.5 W6 테스트 설계
- 핵심 비교 1개: **확인 질문 ON/OFF**(H3), 참가자 내 교차(세션 1·2에 각 조건, 순서 무작위 균형), 세션 3은 참가자가 선택(선호 지표). 순서·학습 효과 명시.
- 관찰 항목(비교 안 함): 온보딩 이탈, AI 고지 인지 시점, 기억 알림 문구 반응, 모드 분포, 기억 후보 처리(H4), 휴식 알림 반응, 음성/텍스트 선호(H2), 모의 플랜 선택(H5).
- 참가자 흐름: 모집 → 동의 → 첫 통화 → 3세션 → 이탈(단계·이유)을 모집자 전원 기준 보고, 재이용 의향은 완료자·전체 모집자를 각각 분모로.
- 의향 vs 실제 재사용: 설문 의향과 자발 세션 수·W7 자발 접속을 분리 보고.
- 건강 척도(PHQ-9/GAD-7) 사용 안 함: 전문가 검토 전 미사용, 사용성·수용성 평가만 ([[claim-bench-7-no-therapy-positioning]]).
- 모든 결과는 탐색적 해석, 효과·안전성 증명으로 쓰지 않음. 가설별 판정은 [[claim-app-8-hypotheses-h1-h5]].
