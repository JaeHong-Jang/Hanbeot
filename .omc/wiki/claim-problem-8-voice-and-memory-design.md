# claim-problem-8-voice-and-memory-design

## 사업계획서용 문장
> 음성은 텍스트보다 감정 단서를 더 많이 담는다. 5개 실험(N=1,772)에서 음성만 듣는 조건의 공감 정확도가 전체적으로 높았고(Kraus 2017), 정보이론적 추정에서는 **감정·풍자 정보량이 오디오 채널에서 텍스트의 10배 이상**이었다(2025 프리프린트). 맥락 기억은 챗봇을 더 지능적·몰입적으로 느끼게 하지만(3주 169명 실험) **축어적 회상은 프라이버시 불안**을 일으키고, **정서적 개방을 먼저 요구할 때는 '낯선 상대'가 더 편하다**(2025). 따라서 한벗의 기억은 ① 가벼운 사실 대화로 라포를 쌓은 뒤 ② 패러프레이즈 방식으로 ③ 사용자가 범위를 통제하도록 설계해야 하며, 고사용이 외로움·의존 증가와 관련된다는 RCT 결과(n=981)에 따라 사용량 알림과 실제 관계로의 연결을 포함해야 한다.

## 최약 등급

## 적용한 검증자 정정
- Kraus는 "음성이 감정 단서를 더 많이 담는다" 수준으로 인용(과장 금지); Yadavalli는 상호정보량 추정이며 치료효과 10배가 아님.
- Fang: '⇒' 대신 '관련'(우선 수정 항목 ⑦); v1·v2 버전 명기.
- Cox 2023은 치실 습관 주제·텍스트 챗봇 → "텍스트는 연속성이 없다"는 근거로 쓰지 않음.
- 음성 연구는 한국어 AI 인식 정확도·사용자 효용을 입증하지 않음 → MVP 테스트로 검증할 항목.
