# topic-app-paper-evidence

상위: [[overview-app-design]]. 설계서 5절 기술 선택마다 근거 논문 [P1]~[P101]을 정리한 진입 페이지다. 원문은 `reports/한벗 기술 논문 근거.md`.

## 목적·작성일·검증 통계
- 작성일 2026-10-26. 설계서 5절 각 항목의 근거 논문, 교수님 1차 피드백 ①②⑤ 답변, 설계서 변경표를 한곳에 둔다.
- 검증은 같은 GPT 계열 검증자 한 명의 판정이라 독립 재현이 아니다. 등급 A는 원출처에서 직접 확인, B는 2차 출처·근사·조건부, C(미확인)는 본문에 사실로 쓰지 않고 4절에 모았다. A는 한벗에서의 효과를 보증하지 않는다.
- 주장 단위 통계: 음성 A51/B5/C32, SER A57/B24/C37, 안전·개인정보·HCI A70/B5/C29.
- 비평 반영: 논문 근거 문서 26건 + 답변 초안 20건 = 46건 중 수정 40, 일부 수정 6.

## 설계 항목별 핵심 논문과 한 줄 결론
- ① VAD: P1 [[src-mckinnon-2026-vad-window]], P2 [[src-picovoice-2026-vad-benchmark]]. Silero 선택을 지지하나 둘 다 영어. 한국어·모바일 소음 오탐률은 W2 실측.
- ② STT: P3 [[src-park-2024-korean-asr-eval]], P4 [[src-bang-2020-ksponspeech]], P5. Whisper large-v2 zero-shot Kspon CER 14.66%. RTZR 독립 검증 없음, 8%는 팀 목표.
- ③ 턴·끼어들기: P6 [[src-daily-2025-smart-turn-v3]] (한국어 96.85%, n=890, 벤더 자체셋), P13, P14, P15, P16, P18. TTFA 1.0s 유지, "달성 불가" 금지.
- ④ SER: P20, P21 [[src-sereval-2024-whisper-crosslingual]], P26 [[src-sogang-2024-aihub-hubert]], P31 [[src-romana-2025-switchboard-affect]], P34 [[src-ren-2024-emo-codec]], P39 [[src-chou-2023-ser-calibration]]. 확인 질문 용도만 지지, 수치 목표는 미보장.
- ⑤ 운율: P47, P48, P33. -25%/+50% 임계는 근거 없음, 임시 기준 유지.
- ⑥ 대화 생성: P49, P51, P53, P54 [[src-kang-2024-esconv-llm-limits]]. 모드 고정은 대응 가설.
- ⑦ TTS: P56 [[src-du-2024-cosyvoice2]], P57, P59. MOS 3.5는 팀 기준.
- ⑧ 메모리: P61 [[src-wu-2024-longmemeval]], P64, P65 [[src-chen-2026-ai-never-forgets]], P67, P68. 갱신·기권·재생성 시험 추가.
- ⑨ 위기: P70 [[src-park-2020-military-suicide-risk]], P73 [[src-mcbain-2025-llm-suicide-alignment]], P74, P79, P82. 2단 구조 효과는 직접 검증.
- ⑩ 동의·개인정보: P83 [[src-huckvale-2019-mental-health-app-privacy]], P85 [[src-wiepert-2024-voice-reidentification]], P87, P88, P100. 24h는 내부 목표.
- ⑪ 사용 시간: P90 [[src-fang-2025-ai-companion-rct]]. 고사용과 외로움은 관련일 뿐 인과 아님, 60분은 임시.
- ⑫ 요약: 직접 연구 없음, P64·P65 간접 근거. 재진술, 긴 인용 금지.

## 설계서 변경표 요약 (3절 18행)
5③ Smart Turn 한국어 수치 병기 / 7.2 TTFA 목표 유지·P50·P95 측정 / 5③ 백채널 생성·입력 판별·TTS 중단 분리 / 5② CER 간투사 규칙 / 5④ 화자 단위 3세트 분리 / 5④-2 0.6 확률 해석 금지 / 5④-1 분노 질문 보류 / 5④ Opus 전후·성별·길이 + 모델 카드 / 8.5 비교 대조군을 일반 확인 질문으로 / 5⑨-3 키워드·태그·결합 비교, STT 포함 전체 경로 / 5⑨-2 상태 전이표·충돌 우선순위 / 5⑨-2 1393 미사용, 1388 자문 / 5⑩ 생체인식정보 조문 인용 / 5⑩-1·4 데이터별 종료 조건·흐름·삭제 범위·재생성 시험 / 8.4 SDK 0개·트래픽 점검·파일럿 적용 / 5⑧ 50문항에 갱신·기권·재생성 / 5⑥ 모드 고정은 가설 / 7.1·7.3 SER·prefetch 비용 실측.

## 빈 곳과 대체 조치 (5절)
한국어 소음 VAD, 조기 종료율, 백채널 오중단, TTS 취소·flush, TTS MOS는 W2 자체 측정. emotion2vec+·SenseVoice 한국어 SER, 화자 독립 격차, Opus+잡음은 W3. 확인 질문 vs 무반응 비교, 기억 승인 마찰, 휴식 알림 효과는 W6 관찰. 한국어 대화 발화 위기 분류는 번역·현지화 세트와 자문(W3~W5). 109 연동·안전 메시징 원문은 W1~W3. 보관 기간 권고 숫자는 팀 정책 + 법무(W5 전).

## 미확인 목록 요약 (4절)
"IEMOCAP 화자 독립 상한 73%", "0.8139보다 낮아 0.70은 보수적", "최소 200발화·20화자" 근거, 음성 감정값의 민감정보 해당 여부, 구법 제39조의6(인용 금지), 1년 미이용 파기(2023 폐지), WHO·AFSP 원문과 109 의뢰 효과는 미확인으로 본문에서 제외. 비평으로 철회한 해석: P85 방향 반전 교정, P73·P75 범위 축소, P67 96%는 시스템 주도 생성 비율.
