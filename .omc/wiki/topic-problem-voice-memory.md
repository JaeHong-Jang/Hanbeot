# topic-problem-voice-memory

# topic-problem-voice-memory

**KQ5. 음성/준언어 단서가 전달하는 감정 정보, 그리고 '맥락을 기억하는 청취자'의 가치**

## Takeaway
음성만 들을 때 상대 감정을 더 정확히 읽는다(Kraus 2017, 5실험 N=1,772 — 실험별 비일관)는 결과와 "운율이 감정·풍자 정보를 텍스트보다 10배 이상 전달"(2025 프리프린트)한다는 정보이론적 추정은 음성 인터페이스의 정당성을 "음성이 감정 단서를 더 많이 담는다" 수준에서 제공한다. 맥락 기억은 지능·몰입 평가를 높이지만(Cox 2023), 정서적 첫 개방 단계에서는 '낯선 상대'가 더 편하고(Cox 2025) 축어적 회상은 프라이버시 불안을 유발하므로 **기억의 방식과 타이밍 설계**가 핵심이다.

## Findings
**음성·운율**
- 5실험 N=1,772: 음성만 조건이 공감 정확도 우수(전체 방향; 실험별 유의성은 미확인) [[src-kraus-2017-voice-only-empathic-accuracy]]
- 감정·풍자 정보량 오디오 10배+, 질문 여부 2.4배 (상호정보량 추정) [[src-yadavalli-2025-prosody-information]]
- 운율만으로 기쁨·슬픔·분노 정서 지식 활성화(점화 과제) [[src-schwartz-pell-2012-prosody-emotion]]
- v1: 음성 챗봇이 초기에 텍스트보다 외로움·의존 완화에 유리(고사용 시 소멸; v2 비유의) [[src-fang-2025-ai-companion-rct]]
- 외로움 감소 매개 'feeling heard' — 음성 vs 텍스트는 미검증(가설) [[src-de-freitas-2024-ai-companions-loneliness]]

**맥락 기억**
- 3주 169명: 이전 발화 참조 챗봇이 더 지능적·몰입적; 축어 인용은 프라이버시 우려 (주제: 치실 습관) [[src-cox-2023-chatbot-memory-reference]]
- Familiar vs Stranger 프레이밍: 정서적 개방 먼저면 Stranger가 편안; 사실 개방 먼저면 Familiar가 더 즐거움 [[src-cox-2025-familiar-stranger-framing]]
- 석사논문: 기억 있는 챗봇이 사용 용이성·태도 개선, 실재감·유용성 비유의 [[src-karelse-2020-chatbot-memory-thesis]]
- 관계 과정 매 회차 감소 — 기억 부재가 원인이라는 해석은 미검증 [[src-croes-antheunis-2021-chatbot-friendship]]
- 접근 중단·역할 변화가 해 — '기억 연속성 상실'과는 다른 사건 [[src-laestadius-2024-replika-dependence]]

**치료적 동맹 유사물**
- Wysa 1,205명: WAI-SR 3.64, bond 3.98(재측정 차이 비유의); 저자 2인 Wysa 소속 [[src-beatty-2022-wysa-therapeutic-alliance]]
- Therabot: 신뢰·협력 수준이 대면 제공자와 비교 가능(직접 비교 아님) [[src-heinz-2025-therabot-rct]]
- 신뢰↑·사회적 매력↑는 의존·문제적 이용과 관련 — 동맹의 양날 [[src-fang-2025-ai-companion-rct]]

## 반대 근거 / 주의
- 음성 연구는 인간 지각·정보량 근거이며 **한국어 AI의 인식 정확도·사용자 효용**을 입증하지 않음(C).
- "텍스트 챗봇은 연속성이 없어 매번 처음부터 설명해야 한다"는 Cox 2023으로 뒷받침되지 않음(불일치, C) — 그 연구가 바로 이전 대화를 참조하는 텍스트 챗봇을 다룸.
- "기억이 동맹을 높이고 사용량 제한이 의존을 낮춘다"는 설계 가설이며 직접 검증 연구 없음(C).
- 미확인(C): Kraus 보충자료 실험별 결과; Thapar 학위논문(Replika vs Kuki); Cox 2025 개별 참여자 발언; De Freitas 15분 조건.

## Gaps
- "장기 기억이 치료적 동맹을 높인다"를 직접 검증한 2024~2025 피어리뷰 RCT 미발견. 한국어 음성 감정 인식/준언어 연구 미확인.
