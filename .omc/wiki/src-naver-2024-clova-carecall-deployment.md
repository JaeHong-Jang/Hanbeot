# src-naver-2024-clova-carecall-deployment

## 서지
- 네이버 클로바 케어콜 확산 현황 보도(2024-09-05) 및 관련 기사
- URL: 쿠키뉴스 https://www.kukinews.com/article/view/kuk202409050089 / 메트로신문 https://www.metroseoul.co.kr/article/20240905500135 / 바이라인네트워크 2025-06 https://byline.network/2025/06/23-435/

## 핵심 내용
- HyperCLOVA 기반 AI 안부전화(음성합성·음성인식)(A, 개발사 1차 설명).
- 2021-11 부산 해운대구 시작, 2024-08 기준 전국 128개 시군구 도입, 사용자 3만 명(B, 네이버 발표 인용).
- **96%는 "관제 운영 파트너의 연결 전화를 포함한 전체 사용자의 응답 비율"**이며 치료 효과·만족도 지표가 아님. 리서치 노트의 "96% 효과적 활용"은 불일치 → 수정.
- 순천시 이상징후 조기 발견 사례: 간경화 응급환자 사례 보도(B, 대조군 연구 아님).
- "네이버클라우드-이모코그 치매 선별·인지훈련 공동연구"(C): 바이라인 링크는 일본 이즈모시 도입 협약 기사로 해당 근거 아님.

## 검증 결과
- 등급: B / 96% 해석 불일치(수정 적용) / 이모코그 C
- 적용된 수정: "관제 파트너의 연결 전화를 포함해 전체 사용자의 96%가 응답".
