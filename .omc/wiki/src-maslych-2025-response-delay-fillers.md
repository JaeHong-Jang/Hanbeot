# src-maslych-2025-response-delay-fillers
## 서지
Maslych et al., 2025, "Mitigating Response Delays ... LLM-powered Intelligent Virtual Agents", CUI '25, arXiv 2507.22352.
## 수치
VR, N=54, 지연 1.5/4.0/6.5s x 필러 없음/인공/자연 9조건 within-subject. 지연 증가 -> 응답 시간 지각·참여·인상·유능성·재사용 의향 하락(p<.0001). 1.5s 최선호 57.41%, 6.5s 최비선호 61.11%, 4초 미만 권고. 자연 필러: 4.0s(p<.01), 6.5s(p<.0001)에서 지각 응답 시간 개선, 1.5s 유의 효과 없음. 인공 필러 무효. 64.81%가 자연 필러 1순위.
## 검증 결과
수치 A. 1.5s 비유의는 효과 0의 증명 아님, 4·6.5s를 "4초 이상 전부"로 일반화 불가(B). 필러 유형 주효과는 일부 지표에서 유의. 영어·VR·단일 대학생 표본.
## 한벗 적용
TTFA 1.5초 이내면 필러 생략이라는 설계값의 방향 근거.
