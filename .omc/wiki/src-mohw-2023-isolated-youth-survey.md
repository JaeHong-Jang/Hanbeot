# src-mohw-2023-isolated-youth-survey

## 서지정보
- 기관: 보건복지부 (연구 수행: 통계청 연구보고서 참조)
- 제목: 2023년 고립·은둔 청년 실태조사
- 연도: 2023.7~8월 조사, 2023.12.13 발표
- 표본: 응답 21,360명 중 위험군 12,105명(56.7%), 심층 8,874명(심리·정서 문항 유효표본 8,436명)
- 조사 대상 연령: **19~39세** (서울신문의 '19~34세' 표기는 부정확 — 검증자 정정)
- URL: 서울신문 https://www.seoul.co.kr/news/society/2023/12/13/20231213500097 ; 통계청 연구보고서 https://www.kostat.go.kr/boardDownload.es?bid=11887&list_no=443301&seq=1

## 핵심 수치·인용 (조사 참여자 기준, 전체 청년 유병률 아님)
- 고립·은둔 시작 시기: **20대 60.5%**, 10대 23.8%, 30대 15.7%.
- 계기: 취업실패 24.1%, **대인관계 23.5%**, 건강 12.4%, 가족 12.4%.
- 심리: 타인의 시선이 두렵다 **62.0%**, 지인 만나기 두렵다 **44.2%**, 희망이 없다 66.3%; 지난 2주 친구·지인 교류 없음 28.7%.
- 자살생각 75.4%, 자살시도 26.7% (10년 이상 고립 시 89.5%/41.9%).
- 탈고립 시도 67.2%; 재고립 **45.6%는 전체 응답자 기준**(시도자 중 비율 아님 — 검증자 정정).
- 외부 도움을 받지 않은 이유: **"몰라서" 28.5%**, 비용 11.9%, 지원기관 없음 10.5%. 필요 지원: 경제 88.7%, 취업·일경험 82.2%.

## 검증 결과 (2026-10-25)
- 조사 대상 연령 19~34세: **C(불일치)** → **19~39세로 수정 (우선 수정 항목 ②)**.
- 응답 구조·시작 시기·자살·심리·도움 미이용·원인: **B** (기사·동시기 보도 대조). 고위험 참여자 표본의 경험 비율이며 전체 청년 유병률로 쓰면 안 됨. 복수응답 여부 병기 필요.
- 재고립 45.6% 분모: **B(불일치)** → 전체 응답자 기준으로 수정.
