# src-aihub-2024-terms

**미확인(C)** — 리서치 노트가 제시한 링크가 잘못된 데이터셋 페이지이므로 감정 데이터셋 약관 근거로 사용 불가.

## 서지정보
공공데이터포털(data.go.kr) 게시 AI Hub 데이터 이용약관 발췌 (리서치 노트 인용).

## URL
- https://www.data.go.kr/data/15146382/fileData.do — **검증 결과 이 링크는 "고양시 어린이 방송 음성 데이터" 페이지**

## 라이선스/상업 이용 (노트 주장, 미검증)
- "AI허브에서 다운로드 받은 데이터로 학습하여 만들어진 AI모델과 서비스는 자유롭게 배포, 활용 가능 … 영리적으로 판매, 활용하는 행위는 제한하지 않으나 AI허브 데이터를 사용하였음을 명시하여야 함"
- NIA·구축기업 사전협의 없는 데이터 재가공 배포는 원칙적 불가

## 핵심 수치
해당 없음. AI Hub '감정 분류를 위한 대화 음성 데이터셋' 자체 스펙(시간·발화 수·화자 수·라벨 체계)도 미확인.

## 검증 결과
- 등급 **C(확인불가)** — 링크 대상 불일치. aihub.or.kr의 해당 데이터셋 페이지와 공통 이용약관 원문을 직접 확보해야 함
