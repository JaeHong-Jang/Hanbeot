# topic-collab-candidate-researchers-map

## 요약
"한국어 음성 감정 인식 + 정신건강 + HCI"에 직접 닿으면서 공식 페이지로 확인된 후보는 10개 연구실/연구자로 압축된다. UNIST 팀빌딩 "UNIST 연구자" 요건을 충족하는 후보는 김태환(AI대학원)·박영우/이경호/김다정(디자인학과)뿐이며, 정두영 교수는 2025년 이후 KAIST 소속이라 매칭 대상이 아니다. 대전(한남대) 인접 후보는 KAIST 이의진·이성주·정두영과 ETRI 노경주다.

## 「한벗」 협업 요청 내용별 매칭 (제안)
- 음성 감정 단서 분석 모델의 독립 평가: 김태환 / 고한석 / 노경주(데이터)
- 위기 신호(109 안내) 프로토콜·과의존 예방 임상 검토: 정두영 / 함병주
- 대학생 30명 테스트의 연구 설계(IRB·인터뷰·로그 분석): 박영우 / 이의진
- 동의 기반 기억 관리·개인정보 보호 설계: 이성주
- "들어줘/조언/정리" 대화 모드의 상담 이론 근거: 고정은

## 지역 분포 (사실) 와 "가장 가까운 강력한 네트워크" (추론, C)
- 대전: KAIST(이의진·이성주·정두영), ETRI(노경주) — 한남대와 동일 도시(사실). "가장 가깝고 강력한"이라는 순위 서술은 검증자 C.
- 울산: UNIST(김태환·박영우·이경호·김다정)
- 서울: 고려대(고한석·함병주), 경희사이버대(고정은) / 광주: 전남대
