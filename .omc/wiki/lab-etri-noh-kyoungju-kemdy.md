# lab-etri-noh-kyoungju-kemdy

## 소속
- 노경주(KyoungJu Noh) 연구원, 한국전자통신연구원(ETRI), 대전. KESDy18/KEMDy19/KEMDy20 데이터셋 제공자(구 ETRI 나눔 계정 kjnoh2)

## 연구 분야
- 한국어 감정 음성·멀티모달(음성·전사·생체신호) 데이터 구축, 생체신호 기반 감정 인식

## 대표 산출물 (2022-2026)
- KEMDy20(19~39세 80명 자유대화 멀티모달), KEMDy19(성우 대화, 7범주+arousal/valence), KESDy18(성우 30명) — 현재 e-PreTX에서 배포 [[src-etri-epretx-kemdy-kesdy-datasets]]
- ETRI KSP 등재 성격 특성 기반 생체신호 감정인식 논문, 2023-12 [[src-etri-2023-ksp-personality-biosignal-emotion]]

## 한벗과의 접점
- 한국어 SER 베이스라인 구축에 필요한 핵심 데이터의 제공자. 라이선스(상업 이용 조건 미확인)·현행 배포 파일 재확인을 위해 ETRI 연구자 협력 자체가 데이터 접근 수단이 됨. [[claim-collab-5-korean-speech-emotion-data-access]]
- 한남대(대전)와 동일 지역.

## 확인 상태
- 공식 페이지 확인됨 (ETRI e-PreTX 이관 데이터 페이지의 제공자 한글·영문 이름, 등급 A)
- 주의: 데이터 제공자 확인은 연구 협력 수락이나 담당 범위를 보장하지 않음. 소속 부서·직위 미확인.

## 컨택 경로
- e-PreTX 데이터 신청 절차(라이선스 동의 → 관리자 승인) 경유. 개인 연락처 미수집.
