# src-atommerce-2025-mindcafe-clinical-expansion

## 서지
- 아토머스(마인드카페) 관련 보도: 유니콘팩토리 2025-11-28, 바이라인네트워크 2024-04
- URL: https://www.unicornfactory.co.kr/article/2025112810353978053 / https://byline.network/2024/04/04-107/

## 핵심 내용
- 2025년 말: 축적된 사용자 심리 데이터·AI를 의료·임상 영역과 연결하는 확장 방향 발표(B, 회사 전략 설명이며 임상 결과 아님). 명상앱 '코끼리'·EAP '밝음' 인수(B, 밝음 인수 2025-11-28 보도).
- **바이라인 2024-04 기사에 "서울대병원과 디지털치료제를 개발한다"고 명시** → 리서치 노트의 "대학병원 공동연구 미확인" 서술은 불일치. 임상시험 세부사항은 별도 미확인.
- "웰트와 업무협약, 접근성 생태계 첫걸음"(C): 해당 기사에서 확인 못 함, 별도 출처 필요.

## 검증 결과
- 등급: B / 대학병원 협업 불일치(수정 적용) / 웰트 협약 C
- 적용된 수정: "서울대병원과 디지털치료제 개발 보도는 있으나 임상시험 세부사항은 미확인". 리서치 노트의 "아토머스조차 대학병원 협업 미확인 → 한벗 차별화" 논거는 삭제.
- 확인일: 2026-10-25
