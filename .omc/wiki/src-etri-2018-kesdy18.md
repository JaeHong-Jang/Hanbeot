# src-etri-2018-kesdy18

## 서지정보
ETRI 나눔터, KESDy18 (Korean Emotional Speech Database 2018) 데이터셋 설명 페이지.

## URL
- https://nanum.etri.re.kr/share/kjnoh2/KESDy18

## 라이선스/상업 이용
- 페이지에 "License Agreement required (Not submitted)" 표시. "Not submitted"는 방문자의 제출 상태이며 라이선스 내용이 아님
- **상업 이용 허용 여부 미확인** — 라이선스 동의서 원문 미확보. ETRI에 직접 확인 필요

## 핵심 수치
- 성우 30명, wav 2,880개, 발화 텍스트, 감정 라벨 xlsx(범주 다수결 + arousal/valence 평균)
- 공개분은 KESDy18_EM (Shure S35 마이크)

## 검증 결과
- 등급 **A** (공식 데이터 설명·파일 목록과 일치)
- 참고: KEMDy19/KEMDy20는 ETRI 502 오류로 **C(확인불가)** → [[src-etri-2020-kemdy]]
