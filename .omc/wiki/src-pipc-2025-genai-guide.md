## 서지정보
개인정보보호위원회(PIPC) 「생성형 AI 개발·활용을 위한 개인정보 처리 안내서」(2025-08-06 공개) — PIPC 공식 발표·첨부 목록 확인, 안내서 사본(itskorea.kr, 표지에 '안' 표시로 최종본 동일성 별도 확인 필요). 보도: 바이라인네트워크, 지디넷코리아(다음 링크; 노트의 "연합뉴스" 표기는 **불일치 C**), 디지털데일리. 추가: 2026-05 이용자용 '생성형 AI 개인정보 보호 가이드' 책자 보도, 세종 뉴스레터(2024 사례집·질의응답집).

## 핵심 내용
- 공개일 2025-08-06 (A)
- 생애주기 4단계: ① 목적 설정 ② 전략 수립 ③ AI 학습·개발(데이터 적법성, PET) ④ 시스템 적용·관리(배포 전 점검, 처리방침 공개·옵트아웃) + 거버넌스 장; 개발 방식 3종: 서비스형 LLM 활용 / 기성 LLM 활용 / 자체 개발 LLM (B)
- 이용자 프롬프트 학습 시 "성능 개선 관련성·이용자 예측 가능성·옵트아웃 제공 여부" 종합 판단 (B; 3요소 충족이 자동 적법은 아님)
- CPO 기획 초기 참여, 감사 로그, PET(가명·익명처리), 외부 API 약관으로 안전성 확보, 배포 전 위협 점검 (B; 권고·의무·상황별 조치를 뭉뚱그려 "요구"로 쓰지 말 것)
- 2026-05 이용자용 가이드 발간(학습 활용 여부, 기록 삭제) (B); 2024 사례집·질의응답집 (B; 두 자료를 모두 2024 발간물로 묶지 말 것)
- 2025-07-08 민관 협의회 AI 가드레일 논의: **C** (접근 실패)

## 검증 결과
- 공개일: **A**. 내용 요약: **B**. 매체 표기: **C(정정)**. 협의회: **C**
