# src-nvspeech-2025
## 서지
NVSpeech, arXiv 2508.04195. 중국어, 단어 수준 준언어 태그 18종.
## 수치
수작업 76h(비공개)+자동 573.4h(공개). 태그 삽입본 선호 CosyVoice 78.7%, CosyVoice2 75.4%(60명). NMOS 3.9/4.0, 태그 재현율 0.60/0.62, kappa>0.85.
## 검증 결과
수치 A, 해석 C. 선호 차이는 태그 삽입만의 효과가 아님(학습 데이터·미세조정·태그 사용이 함께 변함). NMOS는 비언어음·전환의 자연스러움이며 전체 음질(QMOS)이 아니고 전후 NMOS 비교도 없음. 초록·표 간 수치 불일치.
## 한벗 적용
한국어 효과는 미지. 외삽 금지, 한국어 비언어 코퍼스는 별도 구축 필요.
