# src-hannam-2025-enrollment-official

## 서지정보
한남대학교 공식 홈페이지 「한눈에 보는 한남대학교」(대학 소개 > 학교 현황). 대학알리미 2025년 공시 수치를 기관이 직접 게시. 확인일 2026-10-25 (지휘자 직접 열람, 검증자 GPT-6.1 Sol이 검색 색인에서 선행 발견).

## 핵심 수치 (원문 표기 그대로)
- "재적생 수(학부)(2025년 공시기준)": **15,865명**
- "교원(2025년 공시기준)": 977명
- "직원 수": 257명 (기준일 미표기)
- 대학원생 수: 페이지에 없음

## 정의
**재적생** = 재학생 + 휴학생 + 학사학위취득유예생 (교육기본통계 정의). 페이지는 '재적생'으로만 표기하고 재학/재적 구분 설명은 없음. 월 기준일 미표기(교육기본통계 관행상 4월 1일 추정 — 추정이므로 본문에는 쓰지 않음).

## 검증 결과
- **A** — 기관 공식 페이지 원문에서 수치·연도·지표명 확인. 한벗 SOM 분모(한남대 재적 학부생)로 사용 가능.
- 주의: 기존 [[src-hannam-2024-enrollment-namuwiki]]의 11,506명은 2024년 **재학생(휴학 제외)** 정의라 직접 비교 불가. 두 값의 차이(4,359명)를 휴학생 수로 해석하면 안 됨(연도·출처가 다름).
- 재학생(휴학 제외) 2025 수치는 대학알리미 「학생 현황」 원표를 사람이 직접 내려받아야 확보 가능 — 다음 사이클 과제.

## 사용처
- SOM: 한남대 학부 재적생 15,865명(2025, A) → 이전 "약 1.15만(C)"를 교체. [[topic-market-tam-sam-som-assembly]] · [[topic-market-population-base]] · [[overview-market-demand]]
- 전국 SAM 상한(재적 3,016,724, 2025)과 같은 '재적' 정의이므로 비율 계산 시 일관됨: 15,865 / 3,016,724 = 0.53% (계산값). [[claim-market-2-university-students]]
