# src-veluri-2024-synchronous-llms
## 서지
Veluri et al., 2024, Synchronous LLMs as Full-Duplex Dialogue Agents, EMNLP 2024, arXiv 2409.15594.
## 수치
Llama3-8B에 시간 개념 부여, 합성 대화 212k시간+실제 2k시간, 160~240ms 청크. 턴테이킹 상관 0.32/0.31/0.28, 자연스러움 3.72, 의미 3.47(dGSLM 3.95/1.55).
## 검증 결과
A(HTML 요약 경유). **인터넷 지연은 200ms까지 강건하고 240ms에서 하락**(노트의 "240ms까지 견딤"은 정정).
## 한벗 적용
합성 대화로 부족한 실제 데이터를 보충하는 아이디어(한국어 데이터 부족).
