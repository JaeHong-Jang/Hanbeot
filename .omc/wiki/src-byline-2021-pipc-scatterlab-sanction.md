# src-byline-2021-pipc-scatterlab-sanction

## 서지
- 바이라인네트워크 2021-04-29 (개인정보보호위원회 2021-04-28 의결 보도); 세계일보; 참여연대 논평. 이루다 1.0 연혁: CIO Korea.

## 사실
- 개인정보위, 스캐터랩에 **위반행위 8건**으로 과징금 5,550만원 + 과태료 4,780만원 = **총 1억 330만원** (2021-04-28).
- 핵심 사유: '신규 서비스 개발' 문구만으로 챗봇 학습 동의 인정 불가, 카카오톡 대화문장 GitHub 게시, 민감정보 별도 동의 미이행, 14세 미만 아동 정보 수집.
- 국내 개인정보위의 AI 기업 무단 개인정보 처리에 대한 첫 제재 (세계 최초 아님).
- 이루다 1.0: 2020-12-22 출시, 2021-01-11 중단(20일 ≈ 약 3주).

## 검증 결과 (2026-10-25 확인)
- 제재 금액·사유·첫 제재: 등급 **B** (기사 일치; 개인정보위 원결정·보도자료로 교체 권장). "법 조항 8개"는 **위반행위 8건**으로 정정.
- 이루다 1.0 출시·중단 날짜: **C** (원문 대조 미완료).
