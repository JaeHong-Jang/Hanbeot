# src-sensevoice-2026-license-issue-334

## 서지
QwenAudio/SenseVoice 이슈 #334 (가중치 상업 이용 문의). 조회·검증 2026-11-08.

## 수치·기능
- 초기 답변은 상업 이용·파생 가중치 비공개 가능(출처 표기 필요)으로 읽힘.
- 이후 **2026-09-22 "최종 확인 아님" 안내가 추가**됨. 라이선스 소유자·핵심 유지관리자 확인 대기.

## 라이선스
코드 MIT. 가중치 FunASR MODEL_LICENSE(상업 해석 미확정).

## 검증 결과
"공식 최종 확인됨"은 **불일치(C)**. emotion2vec에 같은 협약이라 상업 가능성이 높다는 추정도 확인불가(C): 잠정 해설을 다른 모델의 확정 허가로 전용 불가.

## 한벗 적용
서비스 번들 전 FunASR 측 서면 확인 필요. 그 전까지 연구 실험(R8 태그 병합)에만 사용. 코드 MIT와 가중치 협약을 분리 표기.
